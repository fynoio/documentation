## Template fields

Select **Template** as the **Message Type**. Then, in **External Template Name / ID**, either select a template that is synced on Fyno or enter the name or ID of a template that is not synced.

![](/images/watpl-v2-message-type-template.png)

<Tabs>
<Tab title="Synced template">

Use this when the template is synced on Fyno from Meta or your provider. Learn how to [sync your WhatsApp templates](./external-templates/whatsapp/sync-resync-templates).

<Steps>
<Step title="External Template Name / ID">

Select the template from the dropdown. All the fields are auto-populated once you select the template name. To fetch the latest version of the template, click **Re-sync** next to the template name.

</Step>
<Step title="Template details">

Fyno shows the template's **Integrations**, **WABA/Namespace**, **Language** and **Category**.

<Info>
WhatsApp Marketing notifications have lower delivery rates, as Meta prioritizes user experience by automatically filtering certain messages sent by businesses to users.
</Info>

</Step>
<Step title="Placeholders">

- **Header Placeholder**: Used if the header contains a placeholder, such as "Name". This is populated automatically, and only one placeholder can be added to the header.
- **Body Placeholders**: Specify the placeholders mentioned in the body of your template here.

</Step>
<Step title="Buttons">

The buttons defined in the Meta template are listed here. For a URL button, Fyno shows whether the URL is configured with dynamic content. If it is, add the placeholder for the dynamic part. See [Button configuration](#button-configuration) for each button type.

</Step>
<Step title="Preview">

The Preview on the right shows how the message looks, including its buttons. Until a template is selected, it shows a placeholder.

</Step>
</Steps>

</Tab>
<Tab title="Not synced template">

Use this for providers that do not support template syncing, such as Freshchat. You must enter all the details exactly as they are in the template created in WhatsApp Business Manager or your provider.

<Steps>
<Step title="External Template Name / ID">

Enter the name or ID of the pre-approved Meta template.

</Step>
<Step title="Language">

Enter the language of the template, as configured in WhatsApp Business Manager.

</Step>
<Step title="Header">

Choose the header type (Text, Image, Video or File). If the header has a placeholder, add it in **Header Placeholder**. Only one placeholder can be added to the header.

</Step>
<Step title="Body content and placeholders">

Enter the main content of the message. In **Body Placeholders**, match the variables from your template with the corresponding Fyno placeholders.

![](/images/whatsapp_nonsync_body_placeholders.png)

</Step>
<Step title="Footer">

Optional. Generally used for signatures or sign-offs.

</Step>
<Step title="Buttons">

Optional. Click **Add Buttons** and add the buttons configured in the Meta template. See [Button configuration](#button-configuration) for each button type.

![](/images/3502e0b-meta_action_buttons.png)

</Step>
</Steps>

<Note>
The Preview is not available for a template that is not synced.
</Note>

</Tab>
</Tabs>

## Button configuration

Buttons can be Quick Reply (custom), Call to Action (Visit Website, Call Phone Number, Copy Offer Code), or a combination of these.

<AccordionGroup>
<Accordion title="Quick Reply">

Every Quick Reply has a unique ID, and you can override it by entering a custom ID. For example, if the unique ID is 'Good Product', you can override it with a custom ID like 'Good'. You receive the custom ID on Fyno's Inbound logs page when someone clicks the Quick Reply.

For a template that is not synced, add the Custom ID configured in Meta for each quick reply button. You can add as many quick reply buttons as needed.

![](/images/030f3d1-meta_quick_reply.png)

</Accordion>
<Accordion title="Marketing opt-out">

Recommended if the category is Marketing. The button text and footer text are pre-configured in Meta and can't be edited. In Fyno, configure it as shown below. For a template that is not synced, add Marketing opt-out as a Quick Reply button. When a user clicks **Stop Promotion** in the WhatsApp message, Fyno automatically adds the user to the opt-out list (WhatsApp channel) for the subscription topic linked to the notification event.

![](/images/e77d55b-fyno_marketing_stop.png)

![](/images/a559d3e-marketing_stop.png)

</Accordion>
<Accordion title="Call Phone Number">

The phone number configured in Meta or the BSP is not shown here, and you don't have to enter anything.

![](/images/7ad6a93-meta_phonenumber.png)

</Accordion>
<Accordion title="Call to Action (Visit Website)">

For example, you can add a CTA for a website link in Meta as shown below. The Website URL is a root URL such as `https://fyno.io/` or `https://www.myntra.com/`. If you choose the URL type as **Dynamic**, you need to provide a sample URL as shown below. If the URL type is **Static**, you don't have to add a sample URL.

![](/images/253733c-meta_sample_template.png)

In Fyno, add the dynamic placeholder as shown below. For a template that is not synced, add the placeholder only if the CTA uses a dynamic URL in the Meta template.

![](/images/030112b-meta_cta_placeholder.png)

**Shortened URLs**

In Meta, configure the URL shortened using [Fyno Shorty](./url-shortener) as shown below. Use Fyno Shorty if you want to shorten your URL, track URL clicks, or both.

![](/images/e602a6b-meta_url_shortener.png)

<Info>
Ensure that the Website URL is always set to `https://fy1.in/` when you use Fyno Shorty to shorten the URL.
</Info>

In Fyno, configure it as shown below. If you have more than one URL, add `{{$fyno.$shorty.0.shorty_id}}` for the first URL, `{{$fyno.$shorty.1.shorty_id}}` for the second URL, and so on.

![](/images/0378854-dynamic_url_shorty.png)

</Accordion>
<Accordion title="Copy Offer Code">

Enter the coupon code you want to send with the WhatsApp message.

![](/images/45ec856-meta_coupon_code.png)

</Accordion>
<Accordion title="Flow Settings">

For templates that use a Meta Flow:

- **Flow Token** (optional): Add a unique ID for your flow, or use 'unused'.
- **Additional Data** (optional): If your flow needs a data payload, add it here as a JSON payload.

![](/images/a2e6523c11fa272f10a064197f1738436dbb21ae8be2b1c328dbf4f4be57279d-Flow_settings.png)

</Accordion>
</AccordionGroup>

## Placeholders

Below the **Channels** section on the left, you can find placeholders. Placeholders are denoted by **`{{ }}`** or **Handlebars**. Click a placeholder to open a pop-up window where you can define its parameters. See the comprehensive guide on [Handlebars](https://handlebarsjs.com/guide/).

<Tip title="Did you know?">
You can use a period (.), underscore (\_) or hyphen (-) within the handlebars. Try it now!
</Tip>

<Warning>
You cannot use only numeric values as placeholder keys.
</Warning>

<Warning title="WhatsApp URL redirection will not work">
When providing URLs for files in WhatsApp templates, redirected links (with multiple hops) will not work, as per Facebook policies.
</Warning>

## How to add an unsubscribe link

<Steps>
<Step>

Add the actual unsubscribe URL as a placeholder in the WhatsApp template.

</Step>
<Step>

To reduce the unsubscribe URL length for a better user experience, we recommend using Fyno Shorty to shorten the URL.

</Step>
<Step>

Add `$fyno.$unsubscribe.url` as the key in the placeholders.

</Step>
</Steps>
