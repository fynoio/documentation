You can add new user properties from the:

- Listing page
- User Profiles page

## How to add a new user property from user listing page?

<Steps>
  <Step>To add a new global user property, click on the Properties list CTA at the top right corner of User Profile page. You will see the properties list as shown ![](/images/dd59f5c-Properties_list.png)</Step>
  <Step>
    Click 'ADD NEW'. You will see the datatype of the property you want to add. You can select one of the datatypes
    <ul>
      <li>Date</li>
      <li>String</li>
      <li>Boolean</li>
      <li>List</li>
      <li>Number</li>
    </ul>
    ![](/images/6b9ab6d-add_new_prop.png)
  </Step>
  <Step>For example, if you want to add a list property, then Click List. It will open a popup as shown ![](/images/dc26529-add_new_list_prop.png)</Step>
  <Step>Enter a unique Property name and click 'Create Property'.</Step>
  <Step>Now a new user property with the datatype List is added to all the users.</Step>
  <Step>If you want to see the new property as part of the User Profile table, then enable the toggle in 'See in Table' column.</Step>
</Steps>

## How to add a new user property from user profile page?

<Steps>
  <Step>Go to any user profile to which you want to add a user property and value from User listing page.</Step>
  <Step>To add a new global user property, say, 'wishlist', search for it as shown under User Properties as shown. ![](/images/user_property_wishlist.png)</Step>
  <Step>Click 'Add new property "Wishlist".</Step>
  <Step>Choose the datatype of the user property. ![](/images/05b6d69-choose_datatype.png)</Step>
  <Step>For example, if the data type you chose is 'List', then add the values as shown. ![](/images/3c37cf3-add_items.png)</Step>
  <Step>Click 'Create Property' to add this property to all user profiles.</Step>
</Steps>
