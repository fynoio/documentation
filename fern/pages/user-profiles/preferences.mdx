Preferences make it easy for your users to manage their notification preferences they want and and select preferred channels for receiving notifications.

This can be accomplished by creating Subscription topics that users can toggle on and off, enabling them to specify the channels through which they prefer to receive each notification.

You can access Preferences from the Navigation menu. User -> Preferences.

<Info>The Preferences feature can be accessed only if your user details are managed through Fyno's User Profile.</Info>

## How it works?

<Steps>
  <Step>Create a Section. Section are a group of subscription topics. For example, you can have a section such as Engagement, which will have all the subscription topics linked to Engagement like Resurrection, Activation, etc.</Step>
  <Step>Create a Subscription. Subscriptions are specific type of notification you send to users. For Example, Under Engagement section, you can have subscriptions like Resurrection, Activation etc.</Step>
  <Step>You can add channels to each subscription and select one the states - ON, OFF, REQUIRED.</Step>
  <Step>You can select any subscription while creating a notification event. The list of all notification events will be linked to a particular subscription.</Step>
  <Step>You can add users to Subscription and add the preference of users for any channel linked to the Subscription.</Step>
</Steps>

<Info>If a channel's state is set as "Required," notifications will be sent to that channel regardless of the user's preferences. It's recommended to reserve this state for critical use cases such as OTP.</Info>

## How to create a Section?

To create a new section, navigate to Users -> Preferences.

<Steps>
  <Step>Click 'Create New Section' if you creating your first section or click 'Create+' if you have already sections.</Step>
  <Step>Enter a appropriate name for the section you are creating. ![](/images/b6565c8-section_creation.png)</Step>
  <Step>Once the section is created, it will look like as shown below. ![](/images/f3cd7cf-section_created.png)</Step>
</Steps>

## How to create a Subscription?

<Steps>
  <Step>Under the section, click 'Add Subscription'.</Step>
  <Step>You will see the subscription creation popup as shown below. ![](/images/628ea28-Updated_sub_preferences.png)</Step>
  <Step>Enter an appropriate Subscription name.</Step>
  <Step>
    Select default state for each channel. All the channels with at least 1 integration will be available for selection. You can select one of the states - Required, ON or OFF.
    <ul>
      <li>Required - Users will always receive the notifications.</li>
      <li>ON - Users will receive the notification until they opt-out.</li>
      <li>OFF - Users will not receive the notifications until they opt-in.</li>
    </ul>
  </Step>
  <Step>Click 'Create'.</Step>
  <Step>You will see the Subscription created as shown below. ![](/images/3ddf2a1-New_subscription_created.png)</Step>
  <Step>
    3 channels are configured in this Subscription created above. You can hover over the icons to see their states.
    <ul>
      <li>SMS - Required.</li>
      <li>Email - ON</li>
      <li>Push - OFF</li>
    </ul>
  </Step>
  <Step>Once the notification events are linked to this Subscription ( which will be done while creating Notification event), you will see a count in Notification Events column. You can hover over it to see the notification events linked.</Step>
  <Step>You can enable Display to turn on the visibility of Subscriptions created in Preview or via APIs.</Step>
  <Step>You can either edit or delete the Subscription by clicking on the ellipsis icon.</Step>
</Steps>

### How to enable Unsubscribe in Subscription topic?

Want to give users more control over their subscriptions? Enable the unsubscribe toggle. This lets you add special unsubscribe links (placeholders) to your templates. When users click these links, they'll be unsubscribed from the specific topic that notification was about.

<Steps>
  <Step>For example, if you want to add Unsubscribe link in SMS, enable the Unsubscribe toggle button as shown below. ![](/images/61213f2-Enable_unsubscribe.png)</Step>
  <Step>Please note that, you can't enable Unsubscribe option for Required channels, as the channels tagged as Required will send notifications irrespective of user's preferences.</Step>
</Steps>

## How to add users to a Subscription?

<Steps>
  <Step>Go to Preferences -> Subscription. Click 'Add Users' button.</Step>
  <Step>You will see the below popup to add users to the channels configured in Subscription. ![](/images/1c22e0c-Add_users_subscription.png)</Step>
  <Step>
    In the channel dropdown, you will see the channels configured in Subscription.
    <Note>Only channels with ON or OFF status will be visible here.</Note>
  </Step>
  <Step>For example, to opt-out a user from Email with distinct id 'abcde', you can do it as shown below. ![](/images/b943cfc-opt-in-example.png)</Step>
  <Step>You can add more users by clicking 'Add'.</Step>
  <Step>Once you have added all the users, click 'Add Users'. You will see the users added to the Subscription 'Resurrection' as shown below. ![](/images/c6a6f69-users_added_sub.png)</Step>
  <Step>Notifications sent via Email to this user with subscription 'Resurrection' will be dropped, as the user has selected opt-out for Email.</Step>
  <Step>You can link this Subscription to any notification event. Refer this [document](./notification-event-creation) for the same.</Step>
</Steps>

## How to reorder Sections and Subscriptions?

<Steps>
  <Step>To reorder either section or subscriptions, click Reorder button at the top. ![](/images/d34efd6-Reorder_sub.png)</Step>
  <Step>Now you will be able to drag and drop sections and subscription using the 'drag and drop' icons highlighted. ![](/images/ef5d5c5-update_sub.png)</Step>
  <Step>Once you have re-ordered the sections/subscriptions, you can click 'Update Order' button to save the changes.</Step>
</Steps>

## How to add Global preference for Opt-in or Opt-out?

For example, if you want to opt-out of WhatsApp across all Subscription Topics, do the following.

<Steps>
  <Step>Click Global opt-out as shown below. ![](/images/58403ab-Global_Opt_out.png)</Step>
  <Step>Click 'Add Users'.</Step>
  <Step>
    Select the following:
    <ul>
      <li>Channel - For which channel you want to set Global preference.</li>
      <li>Distinct Id - Distinct Id of the user managed in Fyno.</li>
      <li>Version - Test or Live</li>
      <li>Opt-out - The preference is Opted out by default. You can't change the value.</li>
    </ul>
    You can add as many users as possible by adding 'Add'.
  </Step>
  <Step>Once you have added Global opt-out preference for all the channels and users, click 'Add Users' to add them to Global preference. ![](/images/017a5e8-Global_opt_out_users.png)</Step>
  <Step>You will see the users added to Global opt-out preference as shown below. ![](/images/1f2866b-globa_opt_Out_List.png)</Step>
</Steps>
