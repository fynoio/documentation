You can copy supported resources from one workspace to another workspace that you own. The copy operation is available only if you have the required permission in the source workspace.

| Resource | Description | Notes |
|----------|-------------|-------|
| [Templates](./copying-templates-components) | Copy Fyno Templates from one workspace to another workspace you own. | - Available only to users with the **Owner**, **Super Admin**, and **Workspace Admin** role.<br />- **External Templates** (**Templates → External**) cannot be copied using this process.<br />- Only **Fyno Templates** (**Templates → Fyno**) support copying. |
| [Routes](./routes/copying-routes) | Copy single-channel and omni-channel routes to another workspace you own. | Available only to users with the **Owner**, **Super Admin**, and **Workspace Admin** role. |
| [Notification Events](./copying-notification-events) | Copy notification events to another workspace you own. | Available only to users with the **Owner**, **Super Admin**, and **Workspace Admin** role. |
| [Workflow](./workflows#copying-workflows) | Copy workflows to another workspace you own. | Available only to users with the **Owner**, **Super Admin**, and **Workspace Admin** role. |
