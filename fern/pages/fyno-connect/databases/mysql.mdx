Connect your MySQL database to Fyno Connect with your database credentials. Once connected, you can build cohorts directly from the data in your database.

## Connect your MySQL database

<Steps>
  <Step title="Open MySQL from Databases">
    Go to **Databases** and click **MySQL**. The **Add a MySQL database** pop-up opens.
  </Step>
  <Step title="Enter the connection details">
    Fill in the following fields:

    - **Custom Name**: A name to identify this connection in Fyno Connect.
    - **Host Address**: The host address of your MySQL server.
    - **Database Name**: The name of the database you want to connect.
    - **User Name**: The username used to access the database.
    - **Password**: The password for that user.
    - **TLS Enabled?**: Select this checkbox if your MySQL server uses TLS.

    The host address, database name, user name and password are masked by default. Click the eye icon on a field to view its value.

    ![Add a MySQL database pop-up](/images/fyno-connect-mysql-add-database.png)
  </Step>
  <Step title="Add the database">
    Click **Add Database**. Fyno tests the connection and saves it once the test succeeds. The database then appears under **Connected DBs** on the same page.
  </Step>
  <Step title="Create cohorts">
    You can now create cohorts from the data in your database. See [Create Cohorts](./how-to-create-a-cohort-in-fyno-connect).
  </Step>
</Steps>
