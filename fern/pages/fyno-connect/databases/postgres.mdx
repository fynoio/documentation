Connect your PostgreSQL database to Fyno Connect with a connection URI. Once connected, you can build cohorts directly from the data in your database.

## Connect your PostgreSQL database

<Steps>
  <Step title="Open Postgres from Databases">
    Go to **Databases** and click **Postgres**. The **Add a PostgreSQL database** pop-up opens.
  </Step>
  <Step title="Enter the connection details">
    Fill in the following fields:

    - **Custom Name**: A name to identify this connection in Fyno Connect.
    - **PostgreSQL URI**: Paste your PostgreSQL connection string. The value is masked by default. Click the eye icon to view it.

    ![Add a PostgreSQL database pop-up](/images/fyno-connect-postgres-add-database.png)
  </Step>
  <Step title="Add the database">
    Click **Add Database**. Fyno tests the connection and saves it once the test succeeds. The database then appears under **Connected DBs** on the same page.
  </Step>
  <Step title="Create cohorts">
    You can now create cohorts from the data in your database. See [Create Cohorts](./how-to-create-a-cohort-in-fyno-connect).
  </Step>
</Steps>

## Connection string format

<Tip title="Check your connection string">
  If the connection test fails, make sure your connection string follows the standard format:

  ```
  postgresql://[user[:password]@][host][:port][/dbname][?param1=value1&...]
  ```
</Tip>
