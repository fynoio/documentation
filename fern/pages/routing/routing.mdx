Effective communication needs a reliable, flexible routing system so that messages reach their recipients without delays or failures. Fyno's Routes let you optimize message delivery across multiple providers and channels. There are two types of routes:

- **[Single Channel Route](./routing-introduction)**: Manage multiple providers within one channel, with traffic distribution, failover setups and conditional routing.
- **[Omnichannel Route](./omnichannel-routing-introduction)**: Move between different channels, such as SMS, WhatsApp, Email, Push, InApp and more, so that your message reaches the user on at least one touchpoint.

You can find both by clicking **Routes** in the left navigation, under the **Omni-Channel** and **Single Channel** tabs.

By combining the two, you can build redundancy, improve reliability and maximize engagement with your audience.

## Copy routes to another workspace

You can copy single channel and omnichannel routes from your workspace to other workspaces. Copying is only possible between workspaces that have the same owner.

<Note>
  Only route-related data is copied to the destination workspace. Any dependencies, such as integrations, must be created or copied manually in the destination workspace.
</Note>

### 1. Prepare your destination workspace

<Steps>
  <Step>Create the integrations used by the routes in the destination workspace.</Step>
  <Step>If an omnichannel route uses a single channel route, copy that single channel route first, using the process described in the next section.</Step>
</Steps>

### 2. Copy your routes

<Steps>
  <Step>Make sure you are in the workspace you want to copy the route from.</Step>
  <Step>Click **Routes** in the left navigation, then select the **Omni-Channel** or **Single Channel** tab.</Step>
  <Step>Click the **three dots** icon on the route you want to copy, then select **Copy to another workspace**. ![](/images/route-options-menu.png)</Step>
  <Step>A checkbox now appears next to every route on the page. Select one or more routes to copy.</Step>
  <Step>Click **Copy Selected Single Channel Routes** or **Copy Selected Omni Channel Routes** in the alert above the listing.</Step>
  <Step>
    Choose the version to copy:
    - **Single route with a live version**: choose whether to copy the latest live or the latest test version. If the route only has a test version, that version is copied.
    - **Multiple routes**: the latest live or latest test version of each route is copied, depending on the route.
  </Step>
  <Step>
    In the copy dialog, select the workspaces to copy to from the **Destination workspace(s)** dropdown. All workspaces you are a member of are listed, but only those with the same owner as your current workspace can be selected. You can select up to five workspaces.

    The dialog also lists the route's dependencies, such as integrations. Make sure these are copied to or available in each destination workspace to avoid errors.

    ![](/images/copy-route-to-another-workspace.png)
  </Step>
  <Step>Click **Confirm** to start copying. The copied routes appear in each selected workspace.</Step>
</Steps>

### 3. After copying

Open each copied route in the destination workspace, re-select the integration where applicable, and click **Save** so that the route works correctly.

## How versioning works

Say you copy a route from Workspace A to Workspace B. The version created in Workspace B depends on whether the route already exists there.

### If the route does not exist in Workspace B

The copy is created as **v1 (Test)**.

### If the route already exists in Workspace B

The copy is created as a new version that is neither test nor live. For example, if Workspace B has **v1 (Test)**, the copy is created as **v2**.

To use the copied version:

<Steps>
  <Step>Select **v2** from the version dropdown beside the route name.</Step>
  <Step>Click **Save** to make it **v2 (Test)**, or click **Go Live** to make it **v2 (Live)**.</Step>
</Steps>

<Note>
  Existing versions in the destination workspace are never overwritten, so you decide when to save or make the copied route live.
</Note>
