To put a **Single Channel Route** to use, add it to a notification event in place of a **Provider**.

- **Provider**: Sends a channel's notifications (SMS, WhatsApp and so on) through that one provider. This is the basic setup.
- **Single Channel Route**: Sends the channel's notifications through the route you built, with multiple providers, redundancy and conditions. This lets you set up a complex delivery structure in minutes.

To use a Single Channel Route, select it while setting up the [Configuration](./notification-event-creation#routeprovider) of your notification event in **Notification Events**.
