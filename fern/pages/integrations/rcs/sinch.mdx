Before getting started, ensure you have a Sinch account with RCS enabled.

> **Note:** All required integration details will be provided by the Sinch team upon request. The API credentials used here are different from your Sinch account login credentials.

<Steps>

### Find the Provider

Navigate to the **Integrations** page. Under the **RCS** section, click on the **Sinch** option.

### Configure the Integration

In the pop-up, fill in the following details:

- **Custom name:** Provide a name to help you identify this account within the platform.
- **Username:** API username provided by Sinch.
- **Password:** API password provided by Sinch.
- **App ID:** The application ID shared by Sinch for your RCS setup.
- **Project ID:** The project ID associated with your Sinch account.

### Update Account and Run Test

- **Update Account:** You can edit and update your details here.
> *Note:* Fields that are greyed out cannot be modified.
- **Run Test:** Use this option to test the integration and verify that the saved configuration is correct.

### Complete the Integration

Click on **Add Account** once all required fields are filled in. Your Sinch RCS account will now be successfully configured.

</Steps>
