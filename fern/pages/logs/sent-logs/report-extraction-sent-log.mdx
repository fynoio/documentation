Report extraction enables you to download Sent Logs for both Live and Test environments.

You can download 5 types of report

<ul>
      <li>All Logs</li>
      <li>Summary</li>
      <li>Daily Summary</li>
      <li>[DND Period Logs](#dnd-period-logs-report)</li>
      <li>SMS Delivery (mobile number-wise)</li>
    </ul>


## Steps to extract report

<Steps>
  <Step>Navigate to **Sent Logs**</Step> 
  <Step>Click 'Request Report' on the top right corner.![](/images/sent-logs-request-report.png)</Step>
  <Step>
    Choose the **Version**, select **Type**, **Date Range**, then click **Confirm**. ![](/images/request-report-modal-ui.png)
    <ul>
      <li>**Version:** Test or Live</li>
      <li>**Date Range:** Yesterday, Last 7 days, Last 28 days, Custom (you can select any 30 days within the last 6 months)</li>
    </ul>
    <Note>You can only export data for 30 days at a time. If you want to export for a longer duration, say 90 days, please create multiple reports - D0 to D30 and D31 to D60 and D61-D90.</Note>
  </Step>
  <Step>
    You will get an InApp notification with the message "Your report request xxxxxx is processing!". 
    <Info>Your report will be ready for download within 5 minutes.</Info>
  </Step>
  <Step>Upon the completion of your report, an InApp notification will be sent, along with an email containing a 'Download Report' call-to-action. ![](/images/report_ready_for_download_inapp.png)</Step>
  <Step>Upon clicking 'Download Report,' a popup will appear, as shown below. ![](/images/report_generated_csv.png)</Step>
  <Step>Upon clicking the download link, the report will start downloading.</Step>
</Steps>
<Tip>Download your report within the next 7 days, as the link will expire after that. For example, if you receive the download link on 1st March at 1 PM, the report link will expire by 8th March at 1 PM.</Tip>

## DND Period Logs report

The **DND Period Logs** report lists notifications that fall inside your Do Not Disturb (DND) window, so you can check whether any messages went out during restricted hours.

### Generating the report

Follow the [steps to extract a report](#steps-to-extract-report). In step 3, set **Type** to **DND Period Logs** and choose the period you want to check. Before you click **Confirm**, expand **Optional Additional Filters** and select a **Channel**.

<Note>You don't set the DND start and end times in the form. Fyno takes them from your existing DND settings, as explained in [How the DND window is selected](#how-the-dnd-window-is-selected).</Note>

### Which messages are included

Fyno checks each date in the selected period separately. A message is included if **any one** of these times falls inside that date's DND window:

| Time checked | What it records |
| --- | --- |
| **Request time** | When Fyno received the notification request |
| **Provider submit time** | When Fyno handed the message to the provider |
| **Delivery time** | When the delivery status was received |

For example, a message requested just before the DND window starts but delivered after it begins is still included.

### How the DND window is selected

Fyno picks the DND setting based on the filters you select, in this order:

| Priority | Your filter selection | DND window used |
| --- | --- | --- |
| 1 | Group ID and channel | The DND setting for that exact group and channel |
| 2 | Channel only | The first DND setting that matches the channel |
| 3 | No filter | The first DND setting, whichever it is |
