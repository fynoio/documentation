Inbound logs helps you to view all the responses sent by your users in a conversation mode. To access Inbound logs, go to Navigation Menu -> Logs -> Inbound.

On the page that opens, you will see the following:

- Inbound Logs
- Filters

## Inbound Logs

You will see the inbound logs as shown below.

![](/images/Inboundlogs_list.png)

- Timestamp - Tells you the details of when (date and time) the response was sent by the customer.
- From (Customer No) - Customer's mobile no from which the response is sent.
- To (Business No) - The WhatsApp Business account number that received the customer's message
- Response - Response Type of the customer. It could be one of the following
  - Text
  - Button
  - Image
  - Document
  - Video
  - Contacts
  - Sticker
  - Reaction
  - Location
  - Audio
- Workflow - Workflow which is linked to the notification sent.

Once you click any Inbound log, you will see the Conversation as shown below.

![](/images/Inboundlogs_Conversation.png)

- You can view the messages sent by you and the responses/options selected by the user as a conversation.
- This help you to understand and act on any user responses or queries.
- By default, it shows all the responses received from SMS and WhatsApp. If you want to see only SMS or WhatsApp, you can choose it by clicking on the icon at the top right corner.

<Info>To view the detailed Inbound logs, you need to enable Conversation Logs in Workspace settings.</Info>

## Filters

You can filter the logs based on the criteria mentioned below.

- **Date Range**: Tells you the details of when (date and time) the notification event was triggered. You can select one of the provided options, which are:
  - Today
  - Yesterday
  - Last 7 days
  - Custom - select a date range based on the log retention settings for delivery callback logs. You can see this under Workspace Settings -> Add On's -> Logs Archival
- **From Customer No**: Customer's mobile no from which the response is sent.
- **To Business No**: The WhatsApp Business account number that received the customer's message
- **Workflow Name**: Workflow which is linked to the notification sent.

## Downloading inbound report

To download incoming messages, apply all relevant filters and click 'Download Report' at the top right corner. You will see a popup which shows all the filters applied as shown below.

![](/images/Inboundlogs_downloadreport.png)

Once you click 'Download' button, the report will be downloaded with applied filters.

You will see the below fields in the report:

- Timestamp - Tells you the details of when (date and time) the response was sent by the customer.
- From (Customer No) - Customer's mobile no from which the response is sent.
- To (Business No) - The WhatsApp Business account number that received the customer's message
- Type - This will show the type of response like Interactive, text etc.
- Response - This field will show what the user has responded. If the user responded as part of Meta flow, we will show 'Submitted a flow' as response.
