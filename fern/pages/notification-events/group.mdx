Notification Events Groups help you organize related notification events together. For instance, if you have multiple notification events for different order statuses (Confirmed, Cancelled, Shipped, InTransit, Delivered), you can create an 'Order Management' group and assign all these notification events to it. This makes notification events filtering and management more efficient.

## How to create a Notification Event Group?

<Steps>
  <Step>Navigate to Notification Events page from the left nav.</Step>
  <Step>You will find 'Group' option on the left side of the notification events page.</Step>
  <Step>Click '+' to add a new group.</Step>
  <Step>Enter a group name and you can select the notification events you want to be part of this group. <img src="/images/templates_selected_grouping.png" width="500px" height="auto" /> </Step>
  <Step>Click 'Create Group'.</Step>
  <Step>A new group 'Order_Management' will be created and all the selected notification events will be added to the group.</Step>
  <Step>You can see the new group under 'Groups' section (5 denotes the no of notification events under this group) and also the notification event with 'Group name' in their card. ![](/images/templates_grouped.png)</Step>
</Steps>

<Info>You can add up to 20 Groups.</Info>
