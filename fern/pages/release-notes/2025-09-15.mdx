## 25.3.7

**Release Date:** 15-Sep-2025

---

### 🔹 New Features

- **Campaigns**
  - Introduced support to **create campaigns directly from Excel spreadsheets (`.XLSX` format)**, enabling faster and more efficient bulk campaign creation.

### ⚡ Feature Enhancements

- **Workflows**

  - Added dropdowns to **select payload values** in webhook triggers and API widgets, eliminating manual typing.
  - Introduced a **Response Mapper** for configuring API calls in **Meta Flows**.
  - Enhanced **UX for the search condition widget** for improved usability.
  - Added support to **select multiple incoming mobile numbers** when creating **Inbound Workflows**.

- **Logs**

  - Included **Journey Logs** under **Add-Ons data retention settings** for consistent data management.

- **Notification Events**

  - Improved **readability of configured conditions** when conditional templates are collapsed.

- **Templates**

  - Added **color-coded alerts** to highlight **template quality** for WhatsApp external templates.
  - Introduced the ability to **re-sync individual WhatsApp external templates** as needed.
  - Improved **grouping of integrations** based on **WhatsApp Business Account** for better clarity and organization.

- **Super Admin**
  - Added a new **‘Delegate’ option** under the Profile page to easily **add and manage Super Admin roles**.

### 🛠 Bug Fixes

- **Workflows**

  - Fixed **operator selection issues** when configuring workflow conditions.

- **Templates**

  - Resolved **rich text template preview rendering** issues.
  - Fixed **URL generation** for external WhatsApp templates with **numeric placeholders**.
  - Cleared **previously searched template groups** properly.
  - Fixed **template saving issues** when payloads contained **numeric keys**.

- **Logs**

  - Ensured **correct WhatsApp external template previews** are displayed.

- **Notification Events**
  - Fixed an issue where **previously searched event groups** were not being cleared properly.
