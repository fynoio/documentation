## 26.1.8

Introduced greater flexibility for suppression list management and dynamic email placeholders. Refined the workflow and email editing experience while improving navigation, analytics readability, and platform reliability.

### 🚀 New Features

- **Suppression List Editing**:
  - Managing suppression lists is now more flexible, with the added ability to edit existing suppression list entries.

### ⚡ Feature Enhancements

- **Email Template UX Improvements**:
  - We’ve enhanced the email template editor for a cleaner and more efficient experience.
  - Grouped sender-related fields into a collapsible section to reduce clutter.
  - Repositioned key actions for better usability and workflow.
  - Standardized icons for improved visual consistency.

- **Workflow Builder UI Enhancements**:
  - Improved visual clarity and usability in the workflow builder.
  - Introduced color-coded widgets for easier identification.
  - Enhanced connector node design and alignment.
  - Updated selected and default states for clearer interaction feedback.

- **Groups Sidebar Interaction Improvement**:
  - Navigation feels smoother and more polished.
  - Refined hover transitions between group list items.
  - Reduced abrupt visual changes for a better user experience.

- **Email Configuration Flexibility Improvements**:
  - We’ve enhanced email configuration to support more dynamic and flexible setups.
  - Enabled dynamic placeholders in Cc, Bcc, From Email, and Reply-To fields.
  - Added support for values using {{ }} placeholder format.
  - Updated validation to accept both standard email addresses and dynamic expressions.
  - Improved flexibility when configuring email templates with runtime data.

### 🛠 Bug Fixes

- **Workflow Analytics Readability Fix**:
  - Improved clarity in performance visualizations.
  - Fixed text overlap issues in Node Performance.
  - Improved label placement for better readability across dense data.

- **JSON Editor Cursor Fix**:
  - Resolved a disruptive editing issue.
  - Fixed cursor jump when typing double quotes inside JSON values.
  - Cursor now stays in place for a smoother editing experience.

- **Analytics Label Drawer UX Improvements**:
  - We’ve enhanced the Analytics Label drawer for a smoother and more efficient experience.
  - Pinned Save Changes and Cancel actions to the bottom for easy access.
  - Enabled independent scrolling for the analytics label list.
  - Ensured key actions remain visible at all times.
  - Improved overall usability when working with longer lists.

- **Event Logs Delivery Status Fix**:
  - We’ve resolved an issue with event logs showing inconsistent delivery statuses.
  - Fixed mismatch where messages appeared delivered in summary view but undelivered in detailed view.
  - Improved consistency between overview and log details.
  - Ensured accurate delivery status reporting across all views.
  - Enhanced reliability when reviewing message delivery outcomes.
