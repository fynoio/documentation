
## 26.4.3

This release adds an AI Data Assistant for asking about your notifications in plain words, and PDF generation counts across analytics and the dashboards.

Navigation takes fewer clicks and drops Fyno-specific wording, alarm details have a clearer layout, campaign placeholders accept a fixed value, the status summary collapses to a simpler view, single-channel routes are easier to work with, and the Typst editor covers more languages, alongside fixes to saving large workflows, report extraction, the components list, workflow analytics and DLT template data.

### 🚀 New features

<CardGroup cols={2}>

<Card title="AI Data Assistant" icon="comments">

Ask about your notifications in plain words instead of building filters. A question such as "Show all SMS that failed yesterday" returns a number, a chart, or a list of matching messages.

Answers cover the last 7 days. Request a report when you need more than that. Available on the Logs page and the Dashboard.

[Read more](/docs/logs-overview#ai-data-assistant)

</Card>

<Card title="PDF generation counts" icon="file-pdf">

Event Analytics and Campaign Analytics now show how many PDFs were generated.

The main and central dashboards add a view of PDF generation by notification event, and a trend chart showing how it changes over time. Counts follow the time range and filters you have selected.

</Card>

</CardGroup>

### ⚡ Enhancements

#### Navigation: Fewer clicks and plainer names

<Warning title="Changed behavior">

**Components** has moved under **Templates**, and **External Templates** is now split into **DLT Templates** and **Meta Templates**.

</Warning>

**Dashboard**, **Templates**, **Logs** and **User** are now links as well as expandable sections, so selecting one opens its main page and reveals its sub-pages in a single step. The section stays open while you are in it.

**Alarms** now sits under **Dashboard**, next to **Real-time**. **Routes** opens omni-channel routes directly, with tabs on the page to switch to single-channel.

Fyno-specific wording has also gone. **Fyno Templates** is now simply **Templates**, and **Sent Logs** is now **Logs**.

<AccordionGroup>

<Accordion title="Alarms: A clearer layout for alarm details">

The [alarm](/docs/alarms) details page has been redesigned. The same information is there, laid out so you can take it in at a glance instead of hunting for it.

</Accordion>

<Accordion title="Campaigns: Use a fixed value for a placeholder">

When mapping placeholders while [creating a campaign](/docs/campaign_creation), you can now type a fixed value instead of picking a column from your CSV file or cohort.

Useful when every recipient gets the same text, so you no longer have to add a column to your source data just to carry it. Mapping to a column works exactly as before.

</Accordion>

<Accordion title="Real-time dashboard: Collapse the status summary">

You can now collapse **Failed**, **Error**, **Dropped** and **Timeout** in the status summary on the [Real-time Dashboard](/docs/real-time-dashboard). Collapsed, they appear together in the table as a single **Not Sent** column, for a simpler view when you are watching overall health rather than individual failures.

Expand them again whenever you need the breakdown. The totals stay the same either way.

</Accordion>

<Accordion title="Routes: Single-channel improvements">

A few changes to make [single-channel routes](/docs/routing-introduction) easier to work with:

- The side panel now closes when you select outside it, the same as omni-channel routes and workflows.
- Analytics label is available as a condition, so you no longer have to set it through variables.
- The first step reads **Pick an option to start**, and **Next component** is now **What to do next?**
- Action colours now match the rest of the interface.

</Accordion>

<Accordion title="Components: More languages in the Typst editor">

The Typst editor now includes fonts for Indian scripts, among them Devanagari, Bengali, Tamil, Telugu, Kannada, Malayalam, Gujarati, Gurmukhi and Oriya, as well as Arabic and Urdu, so you can build PDF [components](/docs/components) in those languages.

General-purpose fonts including Poppins, Arimo, Carlito, DejaVu and Liberation are available too.

</Accordion>

</AccordionGroup>

### 🛠 Bug fixes

| Area | Fix |
| --- | --- |
| **Workflows** | Large workflows that used the event response in a condition could not be saved, failing with an error. They now save as expected. |
| **Components** | • Creating or deleting a component did not update the list until you refreshed the page. The list and its record count now update straight away.<br />• The AI features in the component builder did not work in every browser. They now work across supported browsers. |
| **Report Extraction** | Reports came back empty when an Indian mobile number was entered without its country code, or an email address was typed in capitals. Indian numbers now work either way, and email addresses match whatever case you use. Numbers for other countries still need their country code. |
| **Workflow Analytics** | The page did not show its empty state correctly when a workflow had no data for the selected period. It now renders as expected. |
| **Templates** | • DLT templates loaded the wrong data. They now fetch the right templates.<br />• Switching between channels briefly showed the previous channel's data. A loading indicator now appears until the new data is ready. |
