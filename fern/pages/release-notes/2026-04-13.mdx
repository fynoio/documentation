## 26.1.7

**Release Date:** 13-Apr-2026

### 🚀 New Features

- **Silent Push Option for iOS Templates**:
  - Added support for configuring silent push notifications in iOS push templates.
  - Users can now send notifications that are delivered in the background without alerting the user, enabling more flexible app experiences.

### ⚡ Feature Enhancements

- **Voice Template UI & Copy Improvements**:
  - Enhanced the voice template experience with clearer UI, improved messaging, and better guidance.
  - Users can now create and test voice templates more intuitively with a consistent interface.

- **Chat Templates UI Consistency Improvements**:
  - Improved the UI across Slack, Teams, and Discord templates to provide a more consistent and unified experience.
  - Includes clearer structuring and a smoother template creation and testing flow.

- **Component Placeholder Visibility in Templates**:
  - Improved visibility of component placeholders in the template editor and during test runs.
  - Makes it easier to configure dynamic values and preview templates accurately.

- **Icons Added to WhatsApp Button Dropdown**:
  - Added icons to the WhatsApp button dropdown to make it easier to identify and select button types while creating templates.

- **Custom Fields for Campaign Reporting in Fyno Connect (Without Callbacks)**:
  - Users can now configure and use custom fields in campaigns without requiring a callback setup.
  - These fields are available in reports, enabling more flexible tracking and analysis.

### 🛠 Bug Fixes

- **Integration Creation Issue Resolved**:
  - Fixed an issue that prevented users from successfully creating integrations.
  - Integrations can now be created without interruptions.

- **Workflow Crashes & Missing Node Connections in Mixpanel Workflows**:
  - Fixed issues where workflows could crash unexpectedly and where node connections were not always displayed correctly.
  - Workflows now load reliably and display all connections as expected.

- **HTTP Mapper Values Available Across Workflow Nodes**:
  - Fixed an issue where HTTP mapper values created in one HTTP node were not accessible in subsequent child HTTP nodes within workflows.
  - Values can now be reused seamlessly across relevant nodes.

- **Password Expiry Tooltip Redirect Issue**:
  - Fixed an issue where interacting with the password expiry tooltip could unintentionally redirect users.
  - The tooltip now behaves as expected without unexpected navigation.

- **Authentication Template UI Issues in Synced Templates**:
  - Fixed multiple UI inconsistencies in authentication templates to improve clarity and overall usability.

- **Windows Dashboard Date Issue**:
  - Fixed an issue where dates were not displayed correctly on the dashboard for Windows users.
  - Dates now appear accurately and consistently.

- **Sinch Cache Key Issue**:
  - Fixed an issue that caused inconsistencies in message processing.
  - Messages are now handled reliably.

- **Fyno Connect: Missing Cohort Column Names in Campaign Mapping**:
  - Fixed an issue where some cohort column names were not visible during campaign mapping.
  - All columns now display correctly for seamless configuration.

- **“Run Test” Disabled in HTML Editor**:
  - Fixed an issue where the “Run Test” option was unavailable in the HTML editor.
  - Users can now test templates seamlessly while editing.
