Duplicate Message Check enables you to drop notifications with the same template ID, channel and destination. This will make sure users don't get duplicate content if its triggered by mistake from your end. Additionally, you can also check placeholders before deciding whether to drop a message or not.

To enable it,

<Steps>
  <Step>Go to Workspace Settings.</Step>
  <Step>Select Add-Ons.</Step>
  <Step>Enable the toggle in Duplicate Message Check.</Step>
</Steps>

Once its enabled, you will be able to see the 'Check for Duplicate' option in notification event page. You can read about it [here](./notification-event-creation#check-for-duplication-optional).
