Fyno allows you to update a user profile or fetch user profile details within a workflow. This is helpful when you need to decide what notifications to send based on a user property, or to update a channel or user property linked to a profile based on the data received in the webhook.

To add a user profile within a workflow, drag and drop the **User Profiles** widget into the workflow. You can perform 5 different actions with it.

![](/images/user_profile_actions.png)

| Action | Use it to |
|---|---|
| **Update/add channel** | Add a new channel or update an existing channel's details. |
| **Remove channel** | Remove one or more channels from the profile. |
| **Update profile details** | Create, update, clear or increment user properties. |
| **Fetch profile details** | Get user properties to use later in the workflow. |
| **Delete profile** | Delete the user profile. |

## Example

The animation below takes one user, Priya, through all five actions in turn: her SMS number is added, her Email channel is removed, her plan is updated and her order count goes up, her plan is fetched for the next step, and finally her profile is deleted.

## Set up the widget

Every action starts with the same two fields. Here they are being filled in.

![Filling in the User Profiles panel](/images/user-profile-setup.gif)

1. Under **Distinct ID value from the payload**, select the variable from the payload that holds the user's distinct ID, for example `{{$input.body.distinct_id}}`.
2. Under **Action**, select the action you want to perform from **Action Type**.

Then fill in the fields for that action.

<Tabs>
  <Tab title="Update/add channel">
    To add a new channel or update the existing channel details, use this action.

    ![](/images/user_profile_add_update.png)

    | Field | What to enter |
    |---|---|
    | **Distinct Id** | Map the user's distinct ID from the payload. |
    | **Action Type** | Update/add channel |
    | **Channel** | Select the channel you want to add or update. |
    | **Variable value from payload** | The value for that channel. For example, to update the SMS channel, select the mobile number from the payload. |

    <Note>
    You can add multiple channel details to add or update.
    </Note>
  </Tab>
  <Tab title="Remove channel">
    To remove channel details from a user profile, use this action.

    ![](/images/user_profile_remove.png)

    | Field | What to enter |
    |---|---|
    | **Distinct Id** | Map the user's distinct ID from the payload. |
    | **Action Type** | Remove channel |
    | **Channel** | Select the channel(s) you want to remove. |
  </Tab>
  <Tab title="Update profile details">
    To update the profile details of an existing user profile, use this action.

    | Field | What to enter |
    |---|---|
    | **Distinct Id** | Map the user's distinct ID from the payload. |
    | **Action Type** | Update profile details |

    Then choose what to do under **Action**:

    | Action | When to use it | Fields |
    |---|---|---|
    | **Create Property** | Add a new property. | **Property Name**: enter the name. **Property Type**: String, Boolean, Date, List or Number. **Property value from payload**: select the value. |
    | **Update Property** | Update an existing property. | **Property Name**: select from the dropdown. **Property value from payload**: select the value. |
    | **Update Property only if empty** | Update an existing property only if it is empty. | **Property Name**: select from the dropdown. **Property value from payload**: select the value. |
    | **Leave empty** | Set an existing property to an empty value. | **Property Name**: select from the dropdown. |
    | **Increment/Decrement numeric value** | Increase or decrease a number property. | **Property Name**: select from the dropdown. **Property value from payload**: select the value. |
  </Tab>
  <Tab title="Fetch profile details">
    To fetch details from a user profile, use this action.

    ![](/images/user_profile_fetch.png)

    | Field | What to enter |
    |---|---|
    | **Distinct Id** | Map the user's distinct ID from the payload. |
    | **Action Type** | Fetch profile details |
    | **Select properties to fetch** | Select one or more user properties from the dropdown. |
  </Tab>
  <Tab title="Delete profile">
    To delete a user profile, use this action.

    ![](/images/user_profile_delete.png)

    | Field | What to enter |
    |---|---|
    | **Distinct Id** | Map the user's distinct ID from the payload. |
    | **Action Type** | Delete profile |
  </Tab>
</Tabs>
