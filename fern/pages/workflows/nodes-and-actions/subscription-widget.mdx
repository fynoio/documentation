The **Subscription** widget activates the process for subscribing or unsubscribing. This happens when a user clicks **Stop Promotions** in a WhatsApp message, or when a user consents to receive WhatsApp marketing notifications.

![Subscription widget](/images/subscription-widget-panel.png)

<Note>
This feature is currently supported only for WhatsApp.
</Note>

| Action | What it does |
|---|---|
| **Opted-Out** | Unsubscribes the user, for example when they tap **Stop promotions**. |
| **Opted-In** | Subscribes the user, for example when they agree to receive marketing messages. |

## Example

Two users get the same WhatsApp promotion. Priya taps **Stop promotions**, so the workflow opts her out. Rahul taps **Shop now**, so the condition is false and he stays subscribed.

![Subscription widget opting a user out](/images/subscription-example.gif)

## Unsubscribe a user from WhatsApp notifications

To unsubscribe a user from WhatsApp notifications, follow the below steps.

<Steps>
  <Step title="Add the Virtual No trigger">
    In the Workflow, configure the WABA number by adding the **Virtual No** trigger.

    ![](/images/workflow_subscription_incoming_message.png)
  </Step>
  <Step title="Add a Condition">
    Drag and drop a **Condition** block and configure it as shown below.

    <Warning>
    It's critical to use the variable `$input.body.simplified.message.text` and the value `Stop promotions`.
    </Warning>

    ![](/images/workflow_subscription_condition.png)
  </Step>
  <Step title="Add the Subscription widget">
    Drag and drop the **Subscription** action and attach it to the **If** block. Then add the Subscription key as `simplified.message.button.payload` and the action as **Opted-Out**.

    ![](/images/workflow_subscription_optout.png)
  </Step>
</Steps>
