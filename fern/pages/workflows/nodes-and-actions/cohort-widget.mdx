The **Cohort** widget is used to work with user segments from Mixpanel. It connects to the **Mixpanel** trigger and tells the workflow which users are in a cohort, who has joined it and who has left it, each time Mixpanel syncs the cohort to Fyno.

The cohort name configured in the widget must exactly match the cohort name available in Mixpanel.

## How the outputs work

The widget has three outputs. Connect the next steps of your workflow to the ones you need.

| Output | Who goes down this path |
| --- | --- |
| **First Run** | All users in the cohort during the initial cohort sync. Use this if you want to do a one time sync. |
| **Added** | Users who joined the cohort since the last sync. |
| **Removed** | Users who left the cohort since the last sync. |

Say you have a Mixpanel cohort called `emi-due` for users whose EMI is due. The animation below shows three syncs and the output each user goes down.

## Steps to configure Cohort Widget

![Entering the cohort name](/images/cohort-widget-setup.gif)

<Steps>
  <Step title="Add the widget">
    Drag and drop the **Cohort** widget into the workflow and connect it to the **Mixpanel** trigger.
  </Step>
  <Step title="Enter the cohort name">
    Under **Enter Cohort Name**, type the name in the **Cohort Name** field. The name shows on the widget as you type.

    The entered value should exactly match the cohort name configured in Mixpanel.
  </Step>
  <Step title="Connect the outputs">
    Connect the next workflow steps to **First Run**, **Added** or **Removed**, based on the workflow requirement. For example, send a reminder from **Added** and a thank-you from **Removed**.
  </Step>
  <Step title="Save">
    Save the workflow configuration.

    Each time Mixpanel syncs the cohort, users go down the output that matches what happened to them.
  </Step>
</Steps>

<Note>
The cohort name is case-sensitive and must exactly match the cohort configured in Mixpanel.
</Note>

<Info>
Cohorts can only be connected to the Mixpanel trigger. You can add more than one Cohort widget to the same trigger to handle several cohorts in one workflow. See [Creating a workflow with Mixpanel Cohort](/workflow-using-mixpanel-cohort).
</Info>
