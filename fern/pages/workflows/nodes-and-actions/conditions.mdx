The **Conditions** widget allows you to create conditional branching logic within workflows.

This widget helps workflows evaluate variables dynamically during execution and route users through different workflow paths based on configured conditions.

- If the configured condition evaluates to **true**, the workflow proceeds through the **If** branch.
- If the condition evaluates to **false**, the workflow proceeds through the **Else** branch.

## Example

Say you want premium users to get a premium offer and everyone else a standard one. The **If** branch checks `user_type` equals `premium`. The animation below follows three users through the widget.

## Steps to configure Conditions Widget

Here is the **If** panel being filled in for the example above.

![Filling in the If branch](/images/conditions-widget-setup.gif)

<Steps>
  <Step title="Add the widget">
    Drag and drop the **Conditions** widget into the workflow and connect it to the required workflow step. It adds an **If** and an **Else** branch.
  </Step>
  <Step title="Open the If branch">
    Open the widget configuration panel by clicking the **If** block inside the Conditions widget.
  </Step>
  <Step title="Choose what to check">
    Under **Condition**, select **Variable**. Then select the required variable in **Enter Value**, for example `{{user_type}}`.
  </Step>
  <Step title="Choose the Operator">
    Choose the appropriate **Operator** such as **equals**, **contains**, or other supported comparison operators.
  </Step>
  <Step title="Enter the Value">
    Enter the comparison **Value** that should be evaluated against the selected variable, for example `premium`.
  </Step>
  <Step title="Add more checks (optional)">
    Click **ADD ANOTHER** to add multiple conditions if required. Use the delete icon to remove one.
  </Step>
  <Step title="Connect the branches and save">
    Connect the next workflow steps to both **If** and **Else**, then save the configuration.
  </Step>
</Steps>

<Accordion title="Supported operators">
  - Equals
  - Not Equals
  - Contains
  - Starts With
  - Ends With
  - Greater Than
  - Less Than
  - Greater than or Equal
  - Less than or Equal
  - Is
  - Is Empty
  - In
  - nin
  - is boolean
</Accordion>

## Example Use Cases

| Scenario | Condition |
|---|---|
| Route premium users | `user_type equals premium` |
| Trigger country-specific flow | `country equals US` |
| Check subscription status | `subscription_status equals active` |
| Validate user attributes | `email contains @company.com` |

<Note>
Multiple conditions can be configured within the Conditions widget to support advanced workflow branching and automation logic.
</Note>
