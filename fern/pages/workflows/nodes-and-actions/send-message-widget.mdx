The **Send Message** widget allows users to create and send message templates directly within workflows.

This widget helps workflows trigger communication messages dynamically during workflow execution and supports reusable messaging templates.

The feature is currently available in **Beta**.

# Steps to configure Send Message Widget

<Steps>
  <Step>
    Drag and drop the <b>Send Message</b> widget into the workflow and connect it to the required workflow step.
  </Step>

  <Step>
    Open the widget configuration panel.
  </Step>

  <Step>
    Click <b>CREATE MESSAGE TEMPLATE</b> to create a new message template.
  </Step>

  <Step>
    Configure the message template with the required content, placeholders, and channel-specific details.
  </Step>

  <Step>
    Save the template configuration.

    Once configured, the workflow can use the message template during execution.
  </Step>
</Steps>

# Supported Capabilities

The Send Message widget can be used for:

- Workflow notifications
- Conversational messaging
- Customer communication flows
- Dynamic template-based messaging
- Reusable communication templates

<Note>
The Send Message widget is currently available as a Beta feature and may continue to evolve with additional capabilities and configuration options.
</Note>
