<Info>
The Send Message widget is currently available as a **Beta** feature and may continue to evolve with additional capabilities and configuration options.
</Info>

The **Send Message** widget allows you to create and send message templates directly within workflows.

This widget helps workflows trigger communication messages dynamically during workflow execution and supports reusable messaging templates.

## Example

Say a customer confirms their order and you want to send them a confirmation right away. The **Send Message** widget uses a message template with placeholders, fills them from the workflow data, and sends the message.

![Send Message filling a template and sending it](/images/send-message-example.gif)

| Placeholder | Value from the workflow data |
|---|---|
| `{{name}}` | Priya |
| `{{order_id}}` | O121 |
| `{{delivery_date}}` | 12 Nov |

## Steps to configure Send Message Widget

<Steps>
  <Step title="Add the widget">
    Drag and drop the **Send Message** widget into the workflow and connect it to the required workflow step.
  </Step>
  <Step title="Open the configuration panel">
    Click the widget to open its configuration panel.
  </Step>
  <Step title="Create a message template">
    Click **CREATE MESSAGE TEMPLATE** to create a new message template.
  </Step>
  <Step title="Add the content">
    Configure the message template with the required content, placeholders, and channel-specific details.
  </Step>
  <Step title="Save">
    Save the template configuration.

    Once configured, the workflow can use the message template during execution.
  </Step>
</Steps>
