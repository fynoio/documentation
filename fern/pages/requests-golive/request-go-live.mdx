From the **Go Live** page, you can move your Templates, Routes, Notification Events, Workflows and Components from their Test version to Live. You can also see the full history of version changes for all of them.

<Note>
If you have turned on Approval Request in Security Settings, you will see **Requests** in the navigation menu instead of **Go Live**, and items need to be approved before they go Live. To learn how this works, see [Approval Request](https://fyno.io/docs/approval-request).
</Note>

## What you can take Live

Everything you have saved but not yet taken Live is listed on this page, grouped by feature into tabs. The number next to a tab name shows how many items in that tab are waiting to go Live.

## How to take items Live

<Steps>
  <Step title="Open a tab">
    Open the tab for the feature you want to take Live.
  </Step>
  <Step title="Select the items">
    Select the checkbox next to one or more items. To select every item in the tab at once, use the checkbox in the header row.

    <Tip>
    To find a specific item quickly, type its name in the search box at the top of the page.
    </Tip>
  </Step>
  <Step title="Click GO LIVE">
    Click **GO LIVE**. The button stays greyed out until you select at least one item.

    If Approval Request is turned on, this sends the items for approval instead. See [Approval Request](https://fyno.io/docs/approval-request).
  </Step>
</Steps>

Once an item is Live, you will see it under the **Live** tab.

## What each column shows

### Test version

| Column | What it shows |
| --- | --- |
| **Name** | The name of the Template, Route, Notification Event, Workflow or Component that you have saved in Test and not yet taken Live. |
| **Feature** | The type of feature the item belongs to, for example **Template**. |
| **Test Version** | The test version of the item, such as v1, v2 or v3. |
| **Updated On** | The date and time the test version was last updated. |
| **Created On** | The date and time the item was first created. |

### Live version

| Column | What it shows |
| --- | --- |
| **Name** | The name of the Template, Route, Notification Event, Workflow or Component that has been taken Live. |
| **Feature** | The type of feature the item belongs to, for example **Template**. |
| **Went Live** | When the item went Live. |
| **By** | The person who took the item from Test to Live. |
