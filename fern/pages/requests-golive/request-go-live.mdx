From the **Go Live** page, you can move your Templates, Routes, Notification Events, Workflows and Components from their Test version to Live.

## What you can take Live

Everything you have saved but not yet taken Live is listed on this page, grouped by feature into tabs. The number next to a tab name shows how many items in that tab are waiting to go Live.

## What each column shows

| Column | What it shows |
| --- | --- |
| **Name** | The name of the Template, Route, Notification Event, Workflow or Component that you have saved in Test and not yet taken Live. |
| **Feature** | The type of feature the item belongs to, for example **Template**. |
| **Test Version** | The test version of the item, such as v1, v2 or v3. |
| **Updated On** | The date and time the test version was last updated. |
| **Created On** | The date and time the item was first created. |

## How to take items Live

<Steps>
  <Step title="Open a tab">
    Open the tab for the feature you want to take Live.
  </Step>
  <Step title="Select the items">
    Select the checkbox next to one or more items. To select every item in the tab at once, use the checkbox in the header row.

    ![](/images/go-live-select-items.png)

    <Tip>
    To find a specific item quickly, type its name in the search box at the top of the page.
    </Tip>
  </Step>
  <Step title="Click GO LIVE">
    Click **GO LIVE**, then click **CONFIRM** in the **Go Live Confirmation** dialog. The test versions of the selected items go Live.

    ![](/images/go-live-confirm-items.png)

    If Approval Request is turned on, clicking **GO LIVE** opens the **Request Approval** dialog instead. Select your approvers, add an optional message and click **REQUEST**. See [Approval Request](https://fyno.io/docs/approval-request).

    ![](/images/go-live-request-approval.png)
  </Step>
</Steps>
