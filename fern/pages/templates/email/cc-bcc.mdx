You can add CC and BCC recipients to your email in two ways:

- [Using the Notification Event API](#add-cc-and-bcc-recipients-using-the-api)
- [Using the email editor](#add-cc-and-bcc-recipients-in-the-email-editor)

## Add CC and BCC recipients using the API

Add the CC and BCC details under `channel.email.append` in the Notification Event API, as shown below. You can add any number of emails to CC and BCC.

```cURL title="Add CC and BCC" wordWrap
curl -X POST 'https://api.fyno.io/v1/<WorkspaceID>/test/event' \
-H 'Authorization: Bearer <API_KEY>' \
-H 'Content-Type: application/json' \
-d '{
    "event": "ReleaseNote",
    "to": {
        "email": "xyz@gmail.com"
    },
    "data": {
        "name": "Customer",
        "key": "value"
    },
    "channel": {
        "email": {
            "append": {
                "cc": [
                    {
                        "name": "name1",
                        "email": "abc@gmail.com"
                    }
                ],
                "bcc": [
                    {
                        "name": "name2",
                        "email": "def@gmail.com"
                    }
                ]
            }
        }
    }
}'
```

## Add CC and BCC recipients in the email editor

<Steps>
<Step>

Expand **'From' and 'Cc/Bcc' details entered here will override integration configuration** above the **Subject** field.

</Step>
<Step>

Enter the CC recipients in **Cc** and the BCC recipients in **Bcc**. You can also use placeholders to add CC and BCC details dynamically.

![](/images/emailcreate-v2-override-panel.png)

The same section also has the **From Name**, **From Email**, **Reply To** and **Feedback ID** fields. See [How to override email sender details](./how-to-override-sender-details).

</Step>
</Steps>

<Note>
CC and BCC details provided in the email template override the CC and BCC details provided in the Notification Event API.
</Note>

## CC and BCC details in logs

In the Sent Logs, you find the recipient details (destination, CC and BCC) in the **Summary** tab. For the above example, the Sent Logs show the following information.
