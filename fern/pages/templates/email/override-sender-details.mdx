You can override the sender details configured in your email integration in two ways:

- [Using the Notification Event API](#override-sender-details-using-the-api)
- [Using the email editor](#override-sender-details-in-the-email-editor)

## Override sender details using the API

When you set up the integration, you specify a **From Email** address. If you have multiple email addresses, such as `noreply@xyz.com`, `marketing@xyz.com` and `cs@xyz.com`, and want to use the right one for each communication, you can assign `from_email` dynamically.

<Steps>
<Step title="Define a default From Email">

In the integration pop-up, add a default **From Email**, as shown below. In this example, `tech@fyno.io` is used as the From Email if the email address provided in the payload is not valid.

![](/images/email_default_from_email.png)

<Note>
Adding a default From Email is recommended, to make sure communication is not interrupted.
</Note>

</Step>
<Step title="Pass from_email in the Notification Event API">

In the Notification Event payload, pass `from_email` under `channel.email.override`, as shown below. Emails triggered through this notification event are then sent from `tech@fyno.io`.

```cURL title="Override Sender Details" wordWrap
curl -X POST 'https://api.fyno.io/v1/<WorkspaceID>/test/event' \
-H 'Authorization: Bearer <API_KEY>' \
-H 'Content-Type: application/json' \
-d '{
    "event": "ReleaseNote",
    "to": {
        "email": "xyz@gmail.com"
    },
    "data": {
        "name": "Customer",
        "key": "value"
    },
    "channel": {
        "email": {
            "override": {
                "from_email": "tech@fyno.io"
            }
        }
    }
}'
```

</Step>
</Steps>

<Note>
You can follow the same process for the `from_name` field.
</Note>

## Override sender details in the email editor

<Steps>
<Step>

Expand **'From' and 'Cc/Bcc' details entered here will override integration configuration** above the **Subject** field.

</Step>
<Step>

Enter the sender details you want to override. All fields in this section are optional, and any field you leave empty uses the value configured in your integration.

![](/images/emailcreate-v2-override-panel.png)

| Field | What it overrides |
| --- | --- |
| **From Name** | The sender name the recipient sees. |
| **From Email** | The email address the email is sent from. |
| **Reply To** | The email address replies are sent to. |
| **Feedback ID** (optional) | Your campaign identifier, used to track Gmail spam complaints. Use the format `a:b:c:SenderId`. Currently supported only for the SendGrid provider. |

<Info>
**Feedback ID** is currently supported only for the SendGrid provider.
</Info>

</Step>
</Steps>

<Tip>
The same section also has the **Cc** and **Bcc** fields. See [How to add CC and BCC recipients in email](./how-to-add-cc-bcc-to-email).
</Tip>
