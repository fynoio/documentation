Fyno supports 11 notification channels: SMS, WhatsApp, Email, Slack, Discord, Teams, Push, InApp, Voice, Webpush, and RCS. A template is mandatory for each channel, without which you won't be able to send notifications.

In Fyno, templates serve as the foundation for your notification content. To streamline content management, a single template holds the content for all the channels you need, including SMS, Email, WhatsApp, Push notifications, and more. You choose the channels when you create the template, and you can add more channels to it later.

## Creating a template

<Steps>
  <Step>On the **Fyno Templates** page, click **Create**.</Step>
  <Step>
    In the **Create Template** dialog, enter a **Name** for the template.

    ![](/images/template_create.png)
  </Step>
  <Step>Optionally, choose a group in **Add To Group** to organize templates for easier management.</Step>
  <Step>Under **Select Channels**, select one or more channels, or select **Use all channels** to include every channel.</Step>
  <Step>Click **Submit**.</Step>
</Steps>

The template opens with the selected channels listed in the **Channels** panel on the left. Select a channel to add its content.

## Adding more channels

To add a channel to an existing template, click **Add** in the **Channels** panel and select the channel.

## Test and Live versions

Every template you create is saved as a **Test** version, allowing you to try different variations of content to suit your needs.

Saving a **Test** version does not disturb the **Live** version that may be plugged into your application and active.

When you are confident with the template you have created and tested in the **Test** version, you can move it to the **Live** version by following these steps:

<Steps>
  <Step>Make the final changes to the template and test it to make sure you are getting the desired results.</Step>
  <Step>At the top of the page, next to the template name, you will see the Test version mentioned.</Step>
  <Step>To keep this as a **Test** version, click **Save** and the draft is saved.</Step>
  <Step>To make this **Test** version live, expand the **Save** menu and select **Save and Promote**.</Step>
  <Step>This makes the current version live in the template.</Step>
</Steps>

<Info>
Once a template is live, all the **Notification Events** into which this template is plugged in are automatically updated as well.
</Info>

<Note>
If you have enabled **Approval** in Security Settings, you need to raise an approval request for your changes when you click **Go Live**. See [Approval request](./approval-request) for the steps.
</Note>
