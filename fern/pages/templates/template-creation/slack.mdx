When you add the **Slack** channel to a template, the **Create your Slack Template** screen opens. The Preview on the right shows how the message looks in Slack.

![](/images/slackcreate-v2-editor.png)

## Add the content

Under **Content**, choose how you want to write the message body.

<Tabs>
<Tab title="Text">

Use **Text** to send a simple message. Type your message and use the toolbar above the field for bold, italic, strikethrough and code formatting. You can add placeholders within `{{ }}`.

</Tab>
<Tab title="JSON">

Use **JSON** to send a message built with Slack's Block Kit.

![](/images/slackcreate-v2-json.png)

<Steps>
<Step>

Design your message in the [Slack Block Kit Builder](https://app.slack.com/block-kit-builder).

</Step>
<Step>

Copy the JSON blocks array, from the opening `[` to the closing `]`, as shown below.

![](/images/template_slack_json.png)

</Step>
<Step>

Paste it in the **JSON** tab in Fyno.

</Step>
</Steps>

<Warning>
Handlebars do not work in Slack's Block Kit Builder.
</Warning>

</Tab>
</Tabs>

## Additional Configuration (optional)

Expand **Additional Configuration** to group related notifications into a Slack thread.

| Field | What it does |
| --- | --- |
| **Tag ID** | A unique identifier or placeholder used to create a thread. All consecutive notification events that use the same identifier are added to the same thread. |
| **Tag TTL** | The time period (a numeric value or a placeholder) for which this Tag ID is valid. Enter the value in the first field, and select **Seconds**, **Minutes**, **Hours** or **Days** in the second. |

## Placeholders

Below the **Channels** section on the left, you can find placeholders. Placeholders are denoted by **`{{ }}`** or **Handlebars**. Click a placeholder to open a pop-up window where you can define its parameters. See the comprehensive guide on [Handlebars](https://handlebarsjs.com/guide/).

<Tip title="Did you know?">
You can use a period (.), underscore (\_) or hyphen (-) within the handlebars. Try it now!
</Tip>

<Warning>
You cannot use only numeric values as placeholder keys.
</Warning>

## How to tag users and channels

Use these in your message content:

| Syntax | Who it notifies |
| --- | --- |
| `<!here>` | Only the active members of a channel. |
| `<!channel>` | All members of a channel, active or not. |
| `<!everyone>` | Every person in the #general channel, which is every non-guest member of the workspace. |
| `<@abc.xyz>` | A specific user. For example, use `<@abc.xyz>` to tag the user with the email `abc.xyz@gmail.com`. |

## How to test a Slack template

Use this feature to test a template thoroughly before including it in any Notification Event. This ensures early detection and resolution of any potential issues, for a seamless user experience.

<Steps>
<Step>

Click **Run Test** at the top right of the template. The test pop-up opens.

![](/images/template_slack_test.png)

</Step>
<Step>

Enter the Slack recipient, or a `distinct_id`. **Make sure to enter the distinct_id of a Test User profile.**

- To send a direct message, use `@name`.
- To send a message to a channel, use `#channel_name`. Make sure the Slack app you created is added to that channel.

</Step>
<Step>

Select a Slack integration that is already configured in Fyno.

</Step>
<Step>

Click **Test** to send the message to the recipient with the selected integration. You see the success or failure message along with a link to the Sent Logs.

</Step>
</Steps>

## Save and go live

Click **Save** to save the template as a **Test** version. You can save different versions of the template this way. Use **Go Live** when you are ready to move your template to the **Live** version.

<Note>
If your workspace has a maker-checker workflow enabled for template management, **Go Live** needs an additional approval step. Choose from your designated approvers, who review and authorize the template changes. See [Approval flow](./approval-flow) for the steps.
</Note>
