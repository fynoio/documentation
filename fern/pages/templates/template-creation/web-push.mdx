Fyno's web push templates let you create notifications for both desktop and mobile web, across Windows and macOS devices.

![](/images/webpush_template_creation.png)

## Create a web push template

<Steps>
<Step title="Title (optional)">

Enter the title of the notification. It helps summarize the notification and give it context.

</Step>
<Step title="Message Content">

Enter the body of the notification. This is a required field.

</Step>
<Step title="Icon URL">

Enter the URL of the icon to show on the notification, or upload an image. This is usually your brand logo. This is a required field.

<Tip>
Use an icon with a 1:1 ratio.
</Tip>

</Step>
<Step title="Action URL">

Enter where clicking the notification takes the user. Enter a valid HTTP or HTTPS URL, or a route starting with `/` to route the user within the same path.

</Step>
<Step title="Action Buttons (optional)">

Add up to 3 action buttons. See [Action buttons](#action-buttons).

</Step>
<Step title="Other fields (optional)">

Set the **Tag**, **Image**, **Time to Live** and **Additional Data**. See [Other fields](#other-fields-optional).

</Step>
</Steps>

## Action buttons

You can add up to 3 action buttons. Each button has these settings:

| Setting | What it does |
| --- | --- |
| **Button Title** | The name of the button. |
| **Link** | Where clicking the button takes the user. Enter a valid HTTP or HTTPS URL, such as `https://www.myntra.com/cart?product-id=123`, or a route starting with `/`, such as `/cart?product-id=123`. |
| **Icon** | The button icon, in the format `/img/icon.png`. |

<Note>
The button icon isn't shown in the preview, but it appears in the actual notification.
</Note>

## Other fields (optional)

| Field | What it does |
| --- | --- |
| **Tag** | Only one notification with the same ID is shown on the device. Use the same ID to update an existing notification instead of showing a new one. Maximum 64 characters. |
| **Image** | An image to send with the notification. Enter the image link, or upload an image. Supported file formats are JPG, JPEG and PNG, for desktop and mobile web. |
| **Time to Live** | How long the push message is preserved for delivery if the device is offline or because of OEM device restrictions. The default is 259,200 seconds (3 days). |
| **Additional Data** | Extra information sent with the notification, which can be used to render something on the device. |

<Tip title="Image recommendations">
Keep images under 1MB, with a 2:3 ratio.
</Tip>

## How to test a web push template

Use this feature to test a template thoroughly before including it in any Notification Event. This ensures early detection and resolution of any potential issues, for a seamless user experience.

<Steps>
<Step>

Click **Run Test** at the top right of the template. The test pop-up opens.

![](/images/template_webpush_test_updated.png)

</Step>
<Step>

Enter either the web push token of the recipient, or a `distinct_id`. **Make sure to enter the distinct_id of a Test User profile.**

</Step>
<Step>

Select a web push integration that is already configured in Fyno.

</Step>
<Step>

Click **Test** to send the web push notification to the recipient with the selected integration. You see the success or failure message along with a link to the Sent Logs.

</Step>
</Steps>

## Save and go live

Click **Save** to save the template as a **Test** version. You can save different versions of the template this way. Use **Go Live** when you are ready to move your template to the **Live** version.

<Note>
If your workspace has a maker-checker workflow enabled for template management, **Go Live** needs an additional approval step. Choose from your designated approvers, who review and authorize the template changes. See [Approval flow](./approval-flow) for the steps.
</Note>
