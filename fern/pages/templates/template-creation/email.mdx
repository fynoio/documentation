Fyno's email templates allow you to create templates for both marketing and transactional communication. You can also add placeholders in the subject line to personalise it.

<Info>
To use any user property in your templates, add it in this format: `{{$user.$<user_property>}}`. For example, to add Name as a placeholder from the User profile, add it as `{{$user.$name}}`.
</Info>

## Stripo editor

![](/images/email_stripo_editor.png)

The editor has the following parts:

- **From and Cc/Bcc** (optional): Expand this section to enter sender and Cc/Bcc details. Details entered here override the integration configuration. See [Override Email Sender Details](./how-to-override-sender-details) and [Add CC and BCC Recipients](./how-to-add-cc-bcc-to-email).
- **Subject:** Enter the subject line. You can add placeholders here. Use the attachment icon at the end of the field to add attachments; see [Add Attachments](./how-to-add-attachments-in-email).
- **Toolbar:** Undo, redo and other editing controls, with **Run Test** and **Preview** on the right.
- **Canvas:** Drag content into the drop zones to build your email.
- **Right panel:** Two tabs, **Content** and **Appearance**, described below.

### Content tab

The Content tab holds everything you can drag onto the canvas:

- **Structures:** Row layouts that define the columns of each section.
- **Blocks:** Image, Text, Button, Spacer, Video, Social, Banner, Menu, HTML, Carousel, Accordion and Form. Carousel, Accordion and Form are AMP blocks; see [AMP Email Template](./amp-email-template).
- **Modules:** Saved blocks you can reuse across templates.

### Appearance tab

The Appearance tab sets the default styling for the whole email.

## Save and Go Live

Click **Save** to save the template as a **Test** version. You can save different versions of the template this way. Use **Go Live** when you are ready to move your template to the **Live** version.

<Note>
If you have enabled **Approval** in Security Settings, you need to raise an approval request for your changes when you click **Go Live**. See [Approval request](./approval-request) for the steps.
</Note>

## How to add multiple "to" emails

Pass an array of email addresses in `to` when you trigger the Notification Event. You can add any number of addresses.

```bash title="Add multiple to"
curl -X POST 'https://api.fyno.io/v1/{{WorkspaceId}}/test/event' \
-H 'Authorization: Bearer <API_KEY>' \
-H 'Content-Type: application/json' \
-d '{
    "event": "ReleaseNote",
    "to": {
       "email": ["xyz@fyno.io","abc@fyno.io"]
    },
    "data": {
        "company": "Fyno"
    }
}'
```

## How to test an email template

Use this feature to test a template thoroughly before including it in any Notification Event. This ensures early detection and resolution of any potential issues, for a seamless user experience.

<Steps>
  <Step>Click **Run Test** at the top right of the editor.</Step>
  <Step>The **Test Email template** pop-up opens.</Step>
  <Step>Enter either the email address of the recipient, or a `distinct_id`. **Make sure to enter the distinct_id of a Test User profile.**</Step>
  <Step>Select an email integration that is already configured in Fyno.</Step>
  <Step>Click **Run Test** to send the email to the recipient with the selected integration. You see the success or failure message along with a link to the logs.</Step>
</Steps>

## How to add an unsubscribe link in the header

<Steps>
  <Step>Ensure that the email channel's state within the subscription topic is set to either On or Off.</Step>
  <Step>Make sure the email channel has the unsubscribe feature activated.</Step>
  <Step>Make sure the **Enable one-click unsubscribe** checkbox is ticked.</Step>
  <Step>When an email is triggered with this subscription topic, the unsubscribe link is added to the header automatically.</Step>
  <Step>When the user clicks the unsubscribe link, they see a confirmation pop-up.</Step>
  <Step>Once the user confirms, their email is added to the opt-out list for Email for that subscription topic.</Step>
  <Step>You can view all the users opted out of any channel by opening the subscription topic.</Step>
</Steps>

<Warning title="Add the right subscription topic to your Notification Event">
Unsubscribes are managed at the subscription topic level, so using the wrong subscription topic with a notification event can accidentally unsubscribe users from something they didn't intend.
</Warning>

<Note>
This is currently enabled only for the SES and Postmark service providers. Reach out to us if you want to enable it for any other email service provider.
</Note>

## How to add an unsubscribe link in the footer

<Steps>
  <Step>In the email editor, add a block for Unsubscribe and highlight the word Unsubscribe.</Step>
  <Step>Click the link icon in the toolbar to add a hyperlink to the word.</Step>
  <Step>In the Link settings on the right, choose **Other** from the dropdown and enter the URL, or enter `{{$fyno.$unsubscribe.url}}` if you want to shorten the URL using Fyno Shorty.</Step>
  <Step>We suggest using the original URL rather than Fyno Shorty, since the URL behind the Unsubscribe link isn't visible to users, so Fyno Shorty doesn't add much here.</Step>
  <Step>When the user receives the email and clicks Unsubscribe, a pop-up asks them to confirm that they want to unsubscribe from this subscription topic.</Step>
  <Step>Once the user clicks Confirm, they see a confirmation message.</Step>
  <Step>If they unsubscribed by mistake, they can resubscribe by clicking **Resubscribe**, and they see a success message.</Step>
  <Step>Once unsubscribed, Fyno adds the email to the opt-out list in the respective subscription topic. When you send any email for the same topic, Fyno excludes the user from the payload submitted to the service provider, so the user does not receive it.</Step>
  <Step>In the Sent logs, notifications to unsubscribed users show the response *SUBSCRIPTION "Subscription_topic - User opted-out from channel(channel-state)"*.</Step>
</Steps>

## Uploading email HTML templates

You can upload a custom email template as a `.zip` file. This lets you include your HTML file along with all required assets, such as images.

### What to include in the ZIP file

Your `.zip` file must contain:

- One HTML file, which is used as the email template.
- All static assets referenced in the HTML, such as images and CSS files.

For example, if your HTML references `https://example.com/images/my_image.jpg`, make sure `my_image.jpg` is included inside the `.zip` file.

<Note title="Important guidelines">
- Ensure all asset references in the HTML are correctly linked to files inside the `.zip`.
- Keep the structure simple to avoid broken references.
</Note>

### Error scenarios

The upload fails if:

- The `.zip` file does not contain an HTML file.
- The `.zip` file contains more than one HTML file.

### Warning scenario

If any image or asset is missing, you see a warning message and are prompted to re-upload a corrected `.zip` file with all required assets included.
