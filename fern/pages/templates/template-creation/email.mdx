Fyno's email templates let you create rich emails for both marketing and transactional communication. You can build an email in one of three editors: **Stripo**, **Unlayer** or **HTML**.

## Choose an editor

When you add the **Email** channel to a template, Fyno asks you to choose an editor to create your email template.

![](/images/emailcreate-v2-editor-chooser.png)

| Editor | Use it to |
| --- | --- |
| [Stripo Editor](#stripo-editor) (Recommended) | Build your email from scratch with multiple blocks, with AMP support and branding capabilities. |
| [Unlayer Editor](#unlayer-editor) | Build your email from scratch with multiple blocks, or import JSON from Unlayer. |
| [HTML Editor](#html-editor) | Paste or upload your HTML, if you already have your HTML template code. |

<Tip>
Fyno recommends the Stripo editor because it is easy to use and supports AMP, giving your customers a rich and responsive email experience.
</Tip>

## Fields common to every editor

Every editor has the same fields above the design area:

- **'From' and 'Cc/Bcc' details** (optional): Expand this section to override the **From Name**, **From Email**, **Reply To**, **Cc** and **Bcc** configured in your email integration, and to add an optional **Feedback ID** for tracking Gmail spam complaints (SendGrid only). See [How to override email sender details](./how-to-override-sender-details) and [How to add CC and BCC recipients](./how-to-add-cc-bcc-to-email).

![](/images/emailcreate-v2-override-panel.png)

- **Subject**: Enter the subject line of the email.

![](/images/emailcreate-v2-subject.png)

- **Attachment icon** (paperclip, next to the subject): Add attachments to the email. See [How to add attachments](./how-to-add-attachments-in-email).
- **Run Test** and **Preview**: Send a [test email](#how-to-test-an-email-template), or preview how the email looks.

<Tip>
You can add placeholders in the subject line to personalize it.
</Tip>

<Note>
To use any user property in your templates, add it in this format: `{{$user.$<user_property>}}`. For example, to add Name as a placeholder from the User profile, add it as `{{$user.$name}}`.
</Note>

## Stripo Editor

The Stripo editor has the email canvas on the left and a settings panel with two tabs, **Content** and **Appearance**, on the right. Drag items from the **Content** tab onto the canvas, and drop content into the empty sections.

![](/images/emailcreate-v2-stripo-editor.png)

### Content tab

<AccordionGroup>
<Accordion title="Structures">

Structures set the layout of a row, from a single column up to four columns, or two columns of unequal width. Drag a structure onto the canvas, then drop blocks into its columns.

![](/images/emailcreate-v2-stripo-structures.png)

</Accordion>
<Accordion title="Blocks">

Blocks are the content elements of the email: **Image**, **Text**, **Button**, **Spacer**, **Video**, **Social**, **Banner**, **Menu** and **HTML**. Blocks marked with a lightning icon (**Carousel**, **Accordion** and **Form**) are AMP blocks.

</Accordion>
<Accordion title="Modules">

Modules are saved blocks you can reuse in other templates. Search for a module by name or `#tag`, and switch between grid and list view.

![](/images/emailcreate-v2-stripo-modules.png)

<Tip title="Blocks can be saved!">
When you create a block you want to use again in other templates, save it by clicking the save button next to the block. Give it a name and a tag, and it is then available under **Modules**.
</Tip>

</Accordion>
</AccordionGroup>

### Appearance tab

Use the **Appearance** tab to set the default styles of the whole email.

<AccordionGroup>
<Accordion title="General Settings">

Set the **Message width** (we don't recommend more than 600 pixels), **Message alignment** and **Default padding**. Turn on **More** to set the left, right, top and bottom padding separately.

![](/images/emailcreate-v2-stripo-general-settings.png)

</Accordion>
<Accordion title="Stripes">

Stripes are the horizontal sections of the email. Set the text size and colors for each stripe.

| Stripe | Settings |
| --- | --- |
| **Header** | Text size, Background color, Content background color, Font color, Link color |
| **Content** | Text size, Content background color, Font color, Link color |
| **Footer** | Text size, Background color, Content background color, Font color, Link color |
| **Info area** | Text size, Font color, Link color |

![](/images/emailcreate-v2-stripo-stripes-header.png)

![](/images/emailcreate-v2-stripo-stripes-content.png)

![](/images/emailcreate-v2-stripo-stripes-footer.png)

![](/images/emailcreate-v2-stripo-stripes-info-area.png)

</Accordion>
<Accordion title="Headings">

Set the **Font** and **Line spacing** for headings, and the size, bold, italic and color of **Heading H1**, **H2** and **H3**.

![](/images/emailcreate-v2-stripo-headings.png)

</Accordion>
<Accordion title="Button">

Set the default style of buttons:

- **Support of Outlook**: Inserts a special VML code element so buttons display accurately in MS Outlook email clients. This can increase the email size for each button added.
- **Button color**, **Highlight hovered buttons**, **Font color** and **Text style**.
- **Border radius** and **Border**. Turn on **More** to set each side's border separately.
- **Internal padding**: The left, right, top and bottom padding inside the button.

![](/images/emailcreate-v2-stripo-button-style.png)

![](/images/emailcreate-v2-stripo-button-border.png)

![](/images/emailcreate-v2-stripo-button-padding.png)

</Accordion>
<Accordion title="Mobile Formatting">

These settings work only in the mobile version of the email, in email clients that support media queries. Set the size of the Header, Content, Footer and Info area text, the **Menu** items font size, the size and alignment of **Heading H1**, **H2** and **H3**, the **Button text size**, and whether buttons are **Full-width**.

![](/images/emailcreate-v2-stripo-mobile-text.png)

![](/images/emailcreate-v2-stripo-mobile-headings.png)

</Accordion>
</AccordionGroup>

## Unlayer Editor

The Unlayer editor has a panel with three tabs on the left and the email canvas on the right. Drag content from the left panel onto the canvas.

![](/images/emailcreate-v2-unlayer-editor.png)

- **Content**: The content elements of the email: **Columns**, **Button**, **Divider**, **Heading**, **Paragraph**, **Image**, **Menu** and **HTML**.
- **Blocks**: Saved blocks you can reuse.
- **Body**: Settings for the entire email body.

Use the undo and redo icons above the canvas to reverse or repeat changes, and the desktop and mobile icons to see how the email looks on each device.

## HTML Editor

Use the HTML editor if you already have your HTML template code. Paste your code into the editor, or upload it as a `.zip` file using the upload icon in the toolbar.

![](/images/emailcreate-v2-html-editor.png)

### Upload an HTML template as a .zip file

You can upload a custom email template as a `.zip` file. This lets you include your HTML file along with all the assets it needs, such as images.

Your `.zip` file must contain:

- One HTML file. This is used as the email template.
- All static assets referenced in the HTML, such as images and CSS files.

For example, if your HTML references `my_image.jpg`, make sure `my_image.jpg` is also inside the `.zip` file.

<Note title="Important guidelines">
- Make sure all asset references in the HTML are correctly linked to files inside the `.zip`.
- Keep the structure simple to avoid broken references.
</Note>

The upload fails if:

- The `.zip` file does not contain an HTML file.
- The `.zip` file contains more than one HTML file.

If any image or asset is missing, you see a warning message and are asked to re-upload a corrected `.zip` file with all the required assets.

## How to add multiple 'to' emails

You can add any number of emails to `to` in the Notification Event API, as shown below.

```cURL title="Add Multiple To" wordWrap
curl -X POST 'https://api.fyno.io/v1/<WorkspaceID>/test/event' \
-H 'Authorization: Bearer <API_KEY>' \
-H 'Content-Type: application/json' \
-d '{
    "event": "ReleaseNote",
    "to": {
       "email": ["xyz@fyno.io","abc@fyno.io"]
    },
    "data": {
        "company": "Fyno"
    }
}'
```

## How to test an email template

Use this feature to test a template thoroughly before including it in any Notification Event. This ensures early detection and resolution of any potential issues, for a seamless user experience.

<Steps>
<Step>

Click **Run Test** above the editor. The **Test Email template** pop-up opens.

![](/images/emailcreate-v2-test-modal.png)

</Step>
<Step>

From the dropdown, choose **Email** and enter the email address of the recipient, or choose `distinct_id` and enter it. **Make sure to enter the distinct_id of a Test User profile.**

</Step>
<Step>

In **Email Integration**, select an email integration that is already configured in Fyno.

</Step>
<Step>

**Auto-fill empty placeholders** (optional, AI assistance): If your template has placeholders with no sample values, Fyno can fill them using AI so you can test the email. Click **Yes** to let Fyno fill sample values for the empty placeholders. Once done, you see the message **Sample values have been filled**.

![](/images/emailcreate-v2-test-filled.png)

</Step>
<Step>

Click **Run Test** to send the email to the recipient with the selected integration. You see the success or failure message along with a link to the Sent Logs.

</Step>
</Steps>

## Save and go live

Click **Save** to save the template as a **Test** version. You can save different versions of the template this way. Use **Go Live** when you are ready to move your template to the **Live** version.

<Note>
If your workspace has a maker-checker workflow enabled for template management, **Go Live** needs an additional approval step. Choose from your designated approvers, who review and authorize the template changes. See [Approval flow](./approval-flow) for the steps.
</Note>

## How to add an unsubscribe link in the header

<Steps>
<Step>

Make sure the email channel's state within the subscription topic is set to either **On** or **Off**.

</Step>
<Step>

Make sure the unsubscribe feature is activated for the email channel.

</Step>
<Step>

Make sure the **Enable one-click unsubscribe** checkbox is selected.

![](/images/subscription_enable.png)

</Step>
<Step>

When an email is triggered with this subscription topic, the unsubscribe link is automatically added in the header.

</Step>
<Step>

When the user clicks the unsubscribe link, they see a pop-up as shown below.

![](/images/05e7335-Unsubscribe_popup.png)

</Step>
<Step>

Once the user clicks **Unsubscribe**, their email is added to the email opt-out list for that subscription topic. To view all the users who opted out of any channel, click the subscription topic.

</Step>
</Steps>

<Tip title="Add the right subscription topic to your Notification Event">
Unsubscribes are managed at the subscription topic level, so using the wrong subscription topic with a notification event can unsubscribe users from something they didn't intend.
</Tip>

<Info>
The header unsubscribe link is currently available only for the SES and Postmark integrations. Reach out to us if you want to enable it for any other email service provider.
</Info>

## How to add an unsubscribe link in the footer

<Steps>
<Step>

In the email editor, add a block for Unsubscribe and highlight the word **Unsubscribe**.

</Step>
<Step>

Click the link icon in the toolbar to add a hyperlink to the word.

</Step>
<Step>

In the link settings on the right, choose **Other** from the dropdown. In the text box next to it, enter the unsubscribe URL, or enter `{{$fyno.$unsubscribe.url}}` if you want to shorten the URL using Fyno Shorty.

![](/images/email_unsubscribe.png)

<Tip>
We suggest using the original URL rather than Fyno Shorty. The URL linked to the Unsubscribe text isn't visible to users, so Fyno Shorty doesn't add much here.
</Tip>

</Step>
<Step>

When the user clicks the unsubscribe link in the email, a pop-up asks them to confirm that they want to unsubscribe from this subscription topic.

![](/images/email_unsubscribe_confirmation.png)

</Step>
<Step>

Once the user clicks **Confirm**, they see a confirmation message.

![](/images/email_resubscribe.png)

</Step>
<Step>

If the user unsubscribed by mistake, they can click **Resubscribe**, and they see a success message.

![](/images/b45507c-resubscribed.png)

</Step>
</Steps>

Once a user unsubscribes, Fyno adds their email to the opt-out list of the subscription topic. When you send any email for the same topic, Fyno excludes the user from the payload sent to the service provider, so the user doesn't receive it. In the Sent Logs, you see this response for unsubscribed users: _SUBSCRIPTION "Subscription_topic - User opted-out from channel(channel-state)"_.

![](/images/40de23c-unsub_response.png)

## How to view change logs

To view the history of all the modifications made to a template, use the change logs feature.

Click the history icon at the top right corner of the template page to view the change logs. It shows the following details:

- Who updated it
- Which version was updated
- The date and time it was updated

![](/images/email_template_changelog.png)
