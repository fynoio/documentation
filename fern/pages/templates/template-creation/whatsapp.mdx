WhatsApp templates are easy to use but can get complex, depending on what you are trying to achieve through your messages. Since Meta covers all use cases, we have replicated the same in Fyno for ease of use.

## Creating a WhatsApp template

<Steps>
  <Step>
    On the **Fyno Templates** page, click **Create**, enter a **Name**, select **WhatsApp** under **Select Channels**, and click **Submit**.

    ![](/images/whatsapp_create_template.png)
  </Step>
  <Step>
    The template opens with WhatsApp in the **Channels** panel. Choose a **Message Type** to continue.

    ![](/images/whatsapp_template_creation.png)
  </Step>
</Steps>

<Info>
To use any user property in your templates, add it in this format: `{{$user.$<user_property>}}`. For example, to add Name as a placeholder from the User profile, add it as `{{$user.$name}}`. To use a custom property, add it as `{{$user.<user_property>}}`.
</Info>

## Button configuration

<AccordionGroup>
  <Accordion title="Quick Reply">
    Every Quick Reply has a unique ID, and you can override it by entering a custom ID. For example, if the unique ID is 'Good Product', you can override it with a custom ID like 'Good'. You receive the custom ID on Fyno's Inbound logs page when someone clicks the Quick Reply.
  </Accordion>

  <Accordion title="Marketing opt-out">
    Recommended if the category is Marketing. The button text and footer text are pre-configured in Meta and can't be edited. In Fyno, configure it as shown below. When a user clicks **Stop Promotion** in the WhatsApp message, Fyno automatically adds the user to the opt-out list (WhatsApp channel) for the subscription topic linked to the notification event.

    ![](/images/e77d55b-fyno_marketing_stop.png)

    ![](/images/a559d3e-marketing_stop.png)
  </Accordion>

  <Accordion title="Call Phone Number">
    The phone number configured in Meta or the BSP is not shown here.
  </Accordion>

  <Accordion title="Call to Action (Visit Website)">
    For example, you can add a CTA for a website link in Meta as shown below. The Website URL is a root URL such as `https://fyno.io/` or `https://www.myntra.com/`. If you choose the URL type as **Dynamic**, you need to provide a sample URL as shown below. If the URL type is **Static**, you don't have to add a sample URL.

    ![](/images/253733c-meta_sample_template.png)

    In Fyno, add the dynamic placeholder as shown below.

    ![](/images/030112b-meta_cta_placeholder.png)

    **Shortened URLs**

    In Meta, configure the URL shortened using [Fyno Shorty](./url-shortener) as shown below. Use Fyno Shorty if you want to shorten your URL, track URL clicks, or both.

    ![](/images/e602a6b-meta_url_shortener.png)

    <Info>Ensure that the Website URL is always set to `https://fy1.in/` when you use Fyno Shorty to shorten the URL.</Info>

    In Fyno, configure it as shown below. If you have more than one URL, add `{{$fyno.$shorty.0.shorty_id}}` for the first URL, `{{$fyno.$shorty.1.shorty_id}}` for the second URL, and so on.

    ![](/images/0378854-dynamic_url_shorty.png)
  </Accordion>

  <Accordion title="Flow Settings">
    - **Flow Token** (optional): Add a unique ID for your flow, or use 'unused'.
    - **Additional Data** (optional): If your flow needs a data payload, add it here as a JSON payload.

    ![](/images/a2e6523c11fa272f10a064197f1738436dbb21ae8be2b1c328dbf4f4be57279d-Flow_settings.png)

## How to test a WhatsApp template

Use this feature to test a template thoroughly before including it in any Notification Event. This ensures early detection and resolution of any potential issues, for a seamless user experience.

<Steps>
  <Step>Click **Run Test** at the top right of the template.</Step>
  <Step>
    The **Test WhatsApp template** pop-up opens.

    ![](/images/whatsapp_test.png)
  </Step>
  <Step>Enter either the mobile number of the recipient where the WhatsApp message should be sent, or a `distinct_id`. **Make sure to enter the distinct_id of a Test User profile.**</Step>
  <Step>Select a WhatsApp integration that is already configured in Fyno. Use the same integration with which the template was created.</Step>
  <Step>**Auto-fill empty placeholders** (AI assistance): Click **Yes** to let Fyno fill sample values for any empty placeholders in the template.</Step>
  <Step>Click **Run Test** to send the WhatsApp message to the recipient with the selected integration. You see the success or failure message along with a link to the logs.</Step>
</Steps>

## Save and Go Live

Click **Save** to save the template as a **Test** version. You can save different versions of the template this way. When you are ready, click **Go Live** and confirm to move the template and its associated components to the **Live** version.

![](/images/whatsapp_go_live_confirmation.png)

<Note>
If you have enabled **Approval** in Security Settings, you need to raise an approval request for your changes when you click **Go Live**. See [Approval request](./approval-request) for the steps.
</Note>

## Placeholders

Below the **Channels** section on the left, you can find placeholders. Placeholders are denoted by **`{{ }}`** or **Handlebars**. Click a placeholder to open a pop-up window where you can define its parameters. See the comprehensive guide on [Handlebars](https://handlebarsjs.com/guide/).

<Tip title="Did you know?">
You can use a period (.), underscore (\_) or hyphen (-) within the handlebars. Try it now!
</Tip>

<Warning>
You cannot use only numeric values as placeholder keys.
</Warning>

<Warning title="WhatsApp URL redirection will not work">
When providing URLs for files in WhatsApp templates, redirected links (with multiple hops) will not work, as per Facebook policies.
</Warning>

## How to add an unsubscribe link

<Steps>
  <Step>Add the actual unsubscribe URL as a placeholder in the WhatsApp template.</Step>
  <Step>To reduce the unsubscribe URL length for a better user experience, we recommend using Fyno Shorty to shorten the URL.</Step>
  <Step>Add `$fyno.$unsubscribe.url` as the key in the placeholders.</Step>
</Steps>
