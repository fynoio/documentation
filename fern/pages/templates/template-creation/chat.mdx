When you add the **Teams** channel to a template, the **Create your Teams Template** screen opens. The Preview on the right shows how the message looks in Microsoft Teams.

![](/images/teamscreate-v3-editor.png)

## Add the content

Under **Content**, choose how you want to write the message body.

<Tabs>
<Tab title="Text">

Use **Text** to send a simple message. Type your message and use the toolbar above the field for bold, italic, strikethrough and code formatting. You can add placeholders within `{{ }}`.

</Tab>
<Tab title="JSON">

Use **JSON** to send the message body as JSON. You can add placeholders within `{{ }}`.

![](/images/teamscreate-v2-json.png)

</Tab>
</Tabs>

## Placeholders

Below the **Channels** section on the left, you can find placeholders. Placeholders are denoted by **`{{ }}`** or **Handlebars**. Click a placeholder to open a pop-up window where you can define its parameters. You can use Handlebars functions with your placeholders for operations such as date formatting, number formatting and arithmetic operations. See the comprehensive guide on [Handlebars](https://handlebarsjs.com/guide/).

<Tip title="Did you know?">
You can use a period (.), underscore (\_) or hyphen (-) within the handlebars. Try it now!
</Tip>

<Warning>
You cannot use only numeric values as placeholder keys.
</Warning>

## How to test a Teams template

Use this feature to test a template thoroughly before including it in any Notification Event. This ensures early detection and resolution of any potential issues, for a seamless user experience.

<Steps>
  <Step>Click 'Run Test' on the top right hand side of the template.</Step>
  <Step>You can either enter the destination of the recipient or you can enter distinct_id. **Please make sure to enter Distinct_id of Test User profiles**</Step>
  <Step>Select a provider which is already configured in Fyno.</Step>
  <Step>When you click 'TEST', it will send chat message to the recipient with the selected service provider. You will see the success or failure message along with the link for Logs.</Step>
</Steps>

## Save and go live

Click **Save** to save the template as a **Test** version. You can save different versions of the template this way. Use **Go Live** when you are ready to move your template to the **Live** version.

You can read more about it [here](https://fyno.io/docs/approval-flow)
