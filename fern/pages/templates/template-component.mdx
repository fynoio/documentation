The Components feature allows you to build modular, reusable elements such as headers and footers. By creating these components once, you can easily add them into any email you create, saving time and effort.

## How to create a component (except PDF)

<Steps>
  <Step>From the left navigation menu, locate **Components**.</Step>
  <Step>Click 'Components' and it opens up the Components page.</Step>
  <Step>Click 'Create'. You will see a popup as shown below ![](/images/component_create.png)</Step>
  <Step>Give a unique name for your component and choose a component type. In this example, I am creating a Header component called 'On-Boarding'</Step>
  <Step>
    We support 6 different type of components now.
    <ul>
      <li>Header</li>
      <li>Footer</li>
      <li>Banner</li>
      <li>Socials (Any social media icons like Twitter, LinkedIn, FB etc)</li>
      <li>Paragraph</li>
      <li>PDF</li>
    </ul>
  </Step>
  <Step>Once you click 'Submit', it opens the Email editor options. You can choose either 'Stripo' or 'HTML Editor'.</Step>
  <Step>To create a Header, you can drag & drop Image block into the editor and brand logo.</Step>
  <Step>The header will look as shown below. ![](/images/component_myntra_header.png)</Step>
  <Step>Click 'Save' to create a test version of the component or click 'Go live' to create a live version.</Step>
  <Step>Once a component is successfully created, you can access it in Components page. ![](/images/component_created.png)</Step>
</Steps>

  <Step>In the below example, if the brand equals Myntra, it will add the Header , 'On-Boarding' otherwise it will add the default Fyno Header. ![](/images/components_with_handlebar.png)</Step>

## How to create a PDF component

<Note>The **Typst Editor** is the recommended option for creating new PDF components because it creates PDFs faster. Choose the **HTML Editor** only if you already have an existing HTML template that you want to reuse.</Note>

<Steps>
  <Step>Click **Components** to open the Components page.</Step>
  <Step>
    Click **Create**. A pop-up appears as shown below.![](/images/component_pdf_create.png)
  </Step>
  <Step>Enter a unique name for your component and select **PDF** as the component type.</Step>
  <Step>
    We support six different component types:
    <ul>
      <li>Header</li>
      <li>Footer</li>
      <li>Banner</li>
      <li>Socials (social media icons such as Twitter, LinkedIn, Facebook, etc.)</li>
      <li>Paragraph</li>
      <li>PDF</li>
    </ul>
  </Step>
  <Step>
    Click **Submit**, then choose one of the following editors:![](/images/choose_an_editor_to_create_your_pdf.png)
    <ul>
      <li><strong>Typst Editor (Recommended)</strong> – Write your PDF in Typst with JSON placeholders and uploaded image assets.</li>
      <li><strong>No-Code PDF Editor</strong> – Create and format your PDF using the visual editor without writing HTML.</li>
      <li><strong>HTML Editor</strong> – Use this option only if you already have an existing HTML template that you want to reuse.</li>
    </ul>
  </Step>
  <Step>Build your PDF in the editor you chose. Each editor is explained in the tabs below.</Step>
</Steps>

<Tabs>
  <Tab title="Typst Editor">

    Typst is a simple markup language for creating documents. You write plain text with short commands for headings, tables, images, and styling, and Typst turns it into a PDF. It creates PDFs faster than the other editors, which is why it is the recommended option.

    In the Typst Editor, you write the Typst code on one side and see the PDF in a live preview on the other. You can add dynamic data through placeholders and use your own images.

    The example below picks the Typst Editor, writes a simple order invoice, and saves it. The preview fills in as each line is added.

    ![Create a PDF with the Typst Editor](/images/typst-create-pdf.gif)

    #### Editor layout

    The editor has three parts:

    - **Left panel**: Settings, Variables, Assets, Outline, and Errors. Click `<<` to collapse it.
    - **Code editor**: where you write your Typst code.
    - **Preview**: shows the PDF as it will look, and updates as you type.

    ![Typst Editor layout](/images/typst-editor-layout.png)

    Click the icons on the left to move between the panels. The example below sets a password in **Settings**, then opens **Variables**, **Assets**, **Outline**, and **Errors**.

    ![Typst Editor left panel](/images/typst-left-panel.gif)

    #### Starter code

    Every new Typst PDF opens with a small starter template:

    ```typst
    // Placeholders are available as JSON: data.at("key")
    #let data = json("data.json")

    // Uploaded assets are referenced by their file name: image("assets/logo.png")

    #set page(paper: "a4", margin: 2cm)
    #set text(size: 10pt)

    = Hello #data.at("name", default: "there")
    ```

    | Line | What it does |
    | --- | --- |
    | `#let data = json("data.json")` | Loads your placeholder values so you can use them in the PDF. Keep this line. |
    | `#set page(paper: "a4", margin: 2cm)` | Sets the page size and margins. |
    | `#set text(size: 10pt)` | Sets the default text size. |
    | `= Hello #data.at("name", default: "there")` | Adds a heading. It shows the value of `name`, or "there" if no value is sent. |

    #### Settings

    Click the gear icon in the left panel to open **Settings**.

    ![Settings](/images/typst-settings.png)

    | Field | Description |
    | --- | --- |
    | **File Name** | The name of the PDF file. |
    | **Protect with Password** | Select this to lock the PDF with a password. |
    | **Password** | The password needed to open the PDF. This field appears when **Protect with Password** is selected. |

    The page size and margins are set in your Typst code, not in **Settings**.

    #### Variables

    Click the `{ }` icon in the left panel to open **Variables**. Use the **Search** box to find a variable quickly.

    **Placeholders** are replaced with the dynamic data sent in the `data` payload.

    ![Placeholders](/images/typst-placeholders.png)

    1. Next to **Placeholders**, click **+**, or expand the section and click **+ ADD**.
    2. Use the placeholder in your code with `data.at("key")`.

    ```typst
    Hello #data.at("name")
    ```

    To show a fallback value when no data is sent, add a default:

    ```typst
    Hello #data.at("name", default: "there")
    ```

    **System Variables** are values that Fyno already has. They are grouped as **Digest**, **User Properties**, **Subscription**, and **Verify**. Expand a group to see the variables in it.

    ![System Variables](/images/typst-system-variables.png)

    #### Assets

    Click the image icon in the left panel to open **Assets**. This is where you upload images such as your logo.

    ![Assets](/images/typst-assets.png)

    1. Click **Upload assets** or the upload icon next to **Assets**.
    2. Choose your image file.
    3. Use the image in your code with its file name:

    ```typst
    #image("assets/logo.png")
    ```

    #### Outline

    Click the outline icon in the left panel to open **Outline**. It lists the main parts of your code, such as variables and headings, with their line numbers. Use **Filter outline** to narrow the list.

    ![Outline](/images/typst-outline.png)

    #### Errors

    Click the error icon in the left panel to open **Errors**. If something in your code cannot be compiled, the problem is listed here. Click **Fix with AI** to let Fyno AI correct the code for you. When everything is fine, you see **No errors on compilation**.

    ![Errors](/images/typst-errors.png)

    #### Formatting toolbar

    The toolbar above the code editor adds common Typst formatting for you, so you do not have to type it by hand. It includes undo and redo, bold, italic, underline, headings, bulleted and numbered lists, math, code, links, and comments.

    #### Generate with AI

    Click **Generate with AI** at the bottom of the code editor to let Fyno AI write or change the Typst code for you.

    ![Generate with AI button](/images/typst-generate-with-ai-button.png)

    Three options appear. Click the one you need.

    ![Generate with AI](/images/typst-generate-with-ai.png)

    **Create Typst with AI** opens **Create with Fyno AI**. Enter what you need in **Tell us your requirement** and click **Create**.

    ![Create with Fyno AI](/images/typst-create-with-ai.png)

    The example below uses **Create Typst with AI** to build the order invoice from a short description.

    ![Create Typst with AI](/images/typst-generate-with-ai.gif)

    **Convert HTML to Typst** lets you paste your HTML code and click **Convert**. Fyno AI turns it into Typst.

    ![Convert HTML to Typst](/images/typst-convert-html.png)

    **Edit Typst with AI** opens **Edit with Fyno AI**. Describe the changes you want to make and click **Edit PDF**.

    ![Edit with Fyno AI](/images/typst-edit-with-ai.png)

    #### Preview

    The preview on the right shows the number of pages and the PDF itself. Use the zoom list to change the preview size. Choose **Fit**, or a value from **25%** to **200%**.

    ![Preview controls](/images/typst-preview.png)

    Click the fullscreen icon to **Open the fullscreen preview in a new window**.

    ![Open the fullscreen preview in a new window](/images/typst-preview-fullscreen.png)

    Click the download icon to **Save and Download PDF**.

    ![Save and Download PDF](/images/typst-save-download.png)

    Click **Switch Editor** to go back and choose a different editor.

    ![Switch Editor](/images/typst-switch-editor-button.png)

    <Warning>
    Switching the editor removes your current work. Fyno shows **All your changes will be lost** and asks you to confirm. Click **SWITCH** to continue, or **CANCEL** to stay in the Typst Editor.
    </Warning>

  </Tab>
  <Tab title="No-Code PDF Editor">

## How to use a PDF Component in WhatsApp template

You can use a PDF Component in WhatsApp template in 2 ways
- as a Document file in the Header
- as part of the website CTA button

### How to use a PDF Component as Header in WhatsApp template

- From left nav, go to a WhatsApp template (Templates -> Fyno) .
- Copy the component you want to add from the Components section in the navigation. 
- Paste the value in the Header textbox. It will be added as `{{Component '<Component_name>'}}`
- The added component will look as shown below. ![](/images/whatsapp_header_pdf.png)

### How to use a PDF Component as part of website CTA button

Things to be done in WhatsApp External Template 

- In the external template, make sure to add a website button 
- Enable Dynamic URL toggle.
- Enable Track URL check box.

**Things to be done in Fyno Template** 

- From left nav, go to a WhatsApp template (Templates -> Fyno) .
- Copy the component you want to add from the Components section in the navigation. 
- Paste the value in the button textbox. It will be added as `{{Component '<Component_name>'}}`
- The added component will look as shown below. ![](/images/whatsapp_button_pdf.png)

### How to use a PDF Component in SMS template

- From left nav, go to a WhatsApp template (Templates -> Fyno) .
- Copy the component you want to add from the Components section in the navigation. 
- Paste the value in any of the placeholders. It will be added as `{{Component '<Component_name>'}}` as shown below. ![](/images/pdf_component_sms.png)
- Fyno will automatically shorten the URL of the PDF component added and send it in SMS. 

### How to copy components to another workspace

Reusable components can also be copied between workspaces that you own. 

<Callout type="warning">
  **Prerequisite:** You must have the **Owner** role in the destination workspace.
</Callout>

#### Before you copy

* **Independent Copying:** Components are copied independently of templates.
* **Dependencies:** If a template depends on reusable components, make sure to copy the required components *before* copying the template itself.

#### Steps to copy components to another workspace

<Steps>
  <Step>Open the source workspace.</Step>
  <Step>Go to **Templates** → **Fyno**.</Step>
  <Step>Click **Components** in the page header.</Step>
  <Step>Click the three-dot (**⋮**) menu on the component you want to copy.</Step>
  <Step>Select **Copy to another workspace**.</Step>
  <Step>Select one or more components to copy.</Step>
  <Step>Click **Copy Selected Components**.</Step>
  <Step>Select up to five destination workspaces where you have the **Owner** role.</Step>
  <Step>Click **Confirm**.</Step>
</Steps>

The copied components will now be available in the selected destination workspaces.

#### Component versioning

Component versioning follows the same behavior as template versioning:
* **New Components:** If the component does not exist in the destination workspace, it is created as `v1` (Test).
* **Existing Components:** If the component already exists, a new standalone version (for example, `v2`) is created without affecting existing versions. You can later save it as the new Test version or promote it to Live when you are ready.

### How to raise Approval requests

If your workspace has maker-checker workflow enabled for Components, the ‘Go Live’ action requires an additional approval step. You’ll need to choose from your designated approvers who will review and authorize the component related changes.
You can read more about it [here](https://fyno.io/docs/approval-flow)
