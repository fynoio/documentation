The Maker-Checker approval flow enables Clients to add a additional check/approval process to ensure the right content goes Live.

If you have enabled 'Approval Requests' in Security Settings, when you click 'Go Live', you will need to raise an approval request for the changes you have done.

<Steps>
  <Step>You will see the below popup once you click 'Go Live' . Select approvers from the 'From' dropdown. You can choose one or more approvers. You need to write a short message mentioning the reason for approval request. If you select 'Go Live on approval', the feature will go Live once the approver approves the request. Clicking 'Send for Approval' will send the request. ![](/images/maker_checker_request_approval.png)</Step>
  <Step>You will see the approval request in the Template page as shown . You can click 'Cancel' to cancel the request. ![](/images/maker_checker_raised_approval.png)</Step>
  <Step>The approvers will receive an Email, an InApp notification for every approval request.</Step>
  <Step>The approver will see the request in the Template page. The approver can approve or reject from the respective notification event. ![](/images/Approver_view.png)</Step>
  <Step>Also if the approver wants to see all the pending requests, then can see them in the 'Requests' page as shown below. ![](/images/Approval_requests.png)</Step>
  <Step>The approver can choose one or more requests and either Approve or Reject. While rejecting they need to provide a rejection reason.</Step>
  <Step>If the request is Approved, the feature will go Live if the requestor selected 'Go Live on approval' while raising the request. Otherwise, they have to click 'Go Live' to take the feature Live.</Step>
</Steps>
