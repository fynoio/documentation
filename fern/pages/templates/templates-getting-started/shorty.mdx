Fyno Shorty enables you to transform long links into trackable short URLs. You can generate both generic URLs and user specific URLs, which will help you to track clicks at user and channel level.

## How it works?

<Steps>
<Step>Within the template placeholder popup, click the 'Configure' option.
   ![](/images/shorty_placeholders_config.png)</Step>

<Step>Upon clicking, the UI will appear as depicted below. It show the list of URLs present in the placeholders. ![](/images/shorty_enable_toggle.png)</Step>

<Step>Enable the toggle for the URLs for which you want to track the clicks.</Step>

<Step>
  Choose the type of URL you want to generate ![](/images/shorty_configure_type.png)
  <ul>
    <li>**General** : Choose this option if you want to track URL clicks only at Notification Event level and not at channel or user level. This is recommended for use cases like creating product URLs for Google/FB Ads and or you want to track only clicks.</li>
    <li>**User-Level** : Choose this option, if you want to track URL at user and channel level. This is recommended for use cases like sending unique payment links to users and or you want to track the click event at the message level.</li>
  </ul>
</Step>

<Step>**Exclude Channels** - This is optional. You can enable this option if you wish to exclude specific channels from URL shortening. For example, in this scenario where three channels are configured in the template (SMS, WhatsApp, Email). If you prefer not to use the URL shortener for Email, simply choose "Email" from the dropdown menu.
   ![](/images/fyno_shorty_3.png)</Step>
</Steps>

<Info>The shortened URLs generated will remain valid for a duration of 30 days.</Info>
