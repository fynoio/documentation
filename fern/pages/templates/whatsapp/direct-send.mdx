A **Direct Send: Simple Text** message is a utility text message that can be sent directly, without prior Meta approval.

![](/images/whatsapp_direct_send_simple_text.png)

- **Category**: Shown as **Utility**. This is fixed for this message type.
- **Body**: Enter the message text. Use the toolbar above the field for bold, italic, strikethrough and code formatting. Maximum length is 1024 characters.
