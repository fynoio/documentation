## Template fields

When **Message Type** is set to **Pre-approved WhatsApp Template**, the editor looks like this:

![](/images/whatsapp_preapproved_template.png)

<Steps>
  <Step title="Message Type">
    Select **Pre-approved WhatsApp Template**.
  </Step>
  <Step title="External Template Name / ID">
    Select an external template that is synced on Fyno, or enter the name or ID of a pre-approved Meta template that is not synced on Fyno. Learn how to sync your [WhatsApp External Templates](./external-templates) from your providers.

    To fetch the latest version of the template, click **Re-sync** next to the template name.

    ![](/images/whatsapp_resync.png)

    <Info>All the fields are auto-populated once you select the template name.</Info>
  </Step>
  <Step title="Template details">
    Once a template is selected, Fyno shows its **Integrations**, **WABA/Namespace**, **Language** and **Category**.

    <Info>
    WhatsApp Marketing notifications have lower delivery rates, as Meta prioritizes user experience by automatically filtering certain messages sent by businesses to users.
    </Info>
  </Step>
  <Step title="Buttons">
    The buttons defined in the Meta template are listed here. For a URL button, Fyno shows whether the URL is configured with dynamic content. If it is, add the placeholder for the dynamic part. See [Button configuration](./template-creation-whatsapp#button-configuration) for each button type.
  </Step>
  <Step title="Preview">
    The Preview on the right shows how the message looks, including its buttons. Until a template is selected, it shows a placeholder.

    ![](/images/whatsapp_preview.png)
  </Step>
</Steps>

## Placeholders in the template

- **Header Placeholder:** Used if the header contains a placeholder, such as "Name". This is populated automatically, and only one placeholder can be added to the header.
- **Body Placeholders:** Specify the placeholders mentioned in the body of your template here.
- **Flow Settings:** Settings for templates that use a Meta Flow.
