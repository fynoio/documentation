Fyno tracks clicks on WhatsApp **Visit Website** buttons by routing them through [Fyno Shorty](./url-shortener), Fyno's URL shortener. Every click is recorded before the user is sent on to the actual URL.

The setup depends on where you create the WhatsApp template:

- [WhatsApp template created in Fyno](#whatsapp-template-created-in-fyno)
- [WhatsApp template created in Meta or a BSP](#whatsapp-template-created-in-meta-or-a-bsp)

## Choose a tracking type

Whichever way you create the template, you choose one of two URL tracking types.

| | General | User-Level |
| --- | --- | --- |
| **Tracks clicks at** | Notification Event level | User and channel level |
| **Click status in Sent Logs** | No | Yes |
| **Engagement funnel chart in Analytics** | No | Yes |
| **URL engagement chart in Analytics** | Yes, cumulative number of clicks | Yes |
| **Recommended for** | Product URLs for Google or Facebook ads, or when you only need the number of clicks | Unique links per user, such as payment links, or when you need the click event at the message level |

## WhatsApp template created in Fyno

<Steps>
<Step title="Create the WhatsApp template">

Go to **Templates → External** and create a WhatsApp template. See [External templates](./external-templates).

</Step>
<Step title="Add a Visit Website button">

Add a **Visit Website** button and configure the URL.

![](/images/59a9cb346384c2ef782b6666e7c871a4e92a1691a1a29d649ad18ec75b75d13a-external_template_button.png)

You can use one of two URL types:

- **Static URL:** Use this when you send the same URL to all your users, such as your website URL.
  1. Add the button text that appears as the CTA in your WhatsApp message.
  2. Provide a valid website URL.
  3. Select the **Track URL** checkbox.
- **Dynamic URL:** Use this when you send different URLs to different users, such as payment links.
  1. Turn on the **Dynamic URL** toggle.
  2. Add the button text that appears as the CTA in your WhatsApp message.
  3. Provide a valid website URL.
  4. Select the **Track URL** checkbox.

</Step>
<Step title="Submit for approval">

Click **Save** and send the template to Meta for approval.

</Step>
<Step title="Use the template in a Fyno template">

Once the template is approved, go to **Templates → Fyno** and create a template with the **WhatsApp** channel. Choose **Template** as the **Message Type** and select the approved template in **External Template Name / ID**.

</Step>
<Step title="Set the button URL">

In the buttons section, add the placeholder you want to track if you added a dynamic URL. If you added a static URL, you don't have to do anything.

![](/images/91a10205f804447f1958b57b2a6969d406123d9b270266ee69146bd63858c757-dynamic_url_fyno.png)

</Step>
<Step title="Define the placeholder">

Add the same placeholder in the **Placeholders** section in the left panel of the template editor. You can also combine static text and dynamic placeholders, as shown below.

![](/images/template_whatsapp_dynamic_shorty.png)

</Step>
<Step title="Choose the tracking type">

Select **General** or **User-Level**. See [Choose a tracking type](#choose-a-tracking-type).

</Step>
</Steps>

## WhatsApp template created in Meta or a BSP

<Warning>
To track URL clicks on a template created outside Fyno, the button must use the **Dynamic** URL type.
</Warning>

Follow these steps if you create the WhatsApp template in Meta or a service provider such as Kaleyra or Gupshup.

<Steps>
<Step title="Create the template">

Create a WhatsApp template in Meta or your BSP.

</Step>
<Step title="Add a Visit Website button with a dynamic URL">

Add **Visit Website** as the type of action and configure it as follows:

| Setting | Value |
| --- | --- |
| **Button text** | The text that appears as the CTA in your WhatsApp message |
| **URL type** | Dynamic |
| **Website URL** | `https://fy1.in` |
| **Sample URL** | `https://fy1.in` |

![](/images/e6fb4d8c118f96b6726b9e4c72c249a5d66eea7753621481a02d4aab9db1f8ed-dynamic_url_meta.png)

</Step>
<Step title="Sync the approved template">

Once the template is approved, go to **Templates → External** in Fyno and click the **Sync** icon next to WhatsApp. This syncs the template you created in your BSP to Fyno.

</Step>
<Step title="Use the template in a Fyno template">

Go to **Templates → Fyno** and create a template with the **WhatsApp** channel. Choose **Template** as the **Message Type** and select the synced template in **External Template Name / ID**.

</Step>
<Step title="Set the button URL">

In the buttons section, add the placeholder you want to track.

![](/images/91a10205f804447f1958b57b2a6969d406123d9b270266ee69146bd63858c757-dynamic_url_fyno.png)

</Step>
<Step title="Define the placeholder">

Add the same placeholder in the **Placeholders** section in the left panel of the template editor. You can also combine static text and dynamic placeholders, as shown below.

![](/images/template_whatsapp_dynamic_shorty.png)

</Step>
<Step title="Choose the tracking type">

Select **General** or **User-Level**. See [Choose a tracking type](#choose-a-tracking-type).

</Step>
</Steps>
