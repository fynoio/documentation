You can track URL clicks in WhatsApp message.

## Prerequisites

To track URL clicks, you need to enable Fyno Shorty feature. To do so, follow the below steps.

1. Go to Workspace settings -> Add ons -> Fyno Shorty.
2. Enable the toggle.

## How the URL tracking works?

The process for enabling URL tracking varies based on where you create your WhatsApp template:

- WhatsApp template created directly in Fyno
- WhatsApp template created through Meta or other Business Solution Providers (BSPs)

### WhatsApp template created directly in Fyno

If you are creating a WhatsApp template in Fyno and wants to track the URLs in the WhatsApp message, follow the below steps.

<Steps>
  <Step>Go to Template -> External template to create a WhatsApp template. You can read how to create a WhatsApp template here.</Step>
  <Step>Add a button 'Visit Website' ![](/images/59a9cb346384c2ef782b6666e7c871a4e92a1691a1a29d649ad18ec75b75d13a-external_template_button.png)</Step>
  <Step>
    You can have 2 types of URL - Static and Dynamic.
    <ul>
      <li>**Static** - You can use static URL, when you send same URL to all your users like your website URL etc.</li>
      <ol>
        <li>Add a button text which will appear as CTA in your WhatsApp message</li>
        <li>Provide a valid website URL.</li>
        <li>Enable 'Track URL' checkbox.</li>
      </ol>
      <li>**Dynamic** - You can use Dynamic URL when you have to send different URLs to different users like Payment links etc.</li>
      <ol>
        <li>Enable 'Dynamic URL' toggle</li>
        <li>Add a button text which will appear as CTA in your WhatsApp message</li>
        <li>Provide a valid website URL.</li>
        <li>Enable 'Track URL' checkbox.</li>
      </ol>
    </ul>
  </Step>
  <Step>Click 'Save' and send it to Meta for approval.</Step>
  <Step>Once the template is approved, go to _Templates -> Fyno_ and create a Fyno WhatsApp template.</Step>
  <Step>Select 'Synced' and choose the template you got approved in Step 4.</Step>
  <Step>In the buttons section, if you added dynamic URL, add the placeholder which you want to track. In case, if you have added static URL, you don't have to do anything. ![](/images/91a10205f804447f1958b57b2a6969d406123d9b270266ee69146bd63858c757-dynamic_url_fyno.png)</Step>
  <Step>Make sure to add the placeholder in the 'Placeholder' section on the LHS of the template editor.</Step>
  <Step>
    URL Tracking type - There are 2 ways you can track a URL click.
    <ol>
      <li>**General**: Choose this option if you want to track URL clicks only at Notification Event level and not at channel or user level. This is recommended for use cases like creating product URLs for Google/FB Ads and or you want to track only clicks. If you choose this option, you won't see the 'Click' status in the Sent logs or in 'Engagement funnel' chart in Analytics. You will see the cumulative no of clicks under 'URL engagement' chart in analytics.</li>
      <li>**User-Level**: Choose this option, if you want to track URL at user and channel level. This is recommended for use cases like sending unique payment links to users and or you want to track the click event at the message level. If you choose this option, you will see the 'Click' status in the Sent logs and in 'Engagement funnel' chart in Analytics.</li>
    </ol>
  </Step>
</Steps>

### WhatsApp template created outside of Fyno

<Note>If you want to track URL clicks, make sure you select Dynamic URL option.</Note>

If you are creating a WhatsApp template in Meta or any service providers such as Kaleyra, Gupshup etc, and wants to track the URLs in the WhatsApp message, follow the below steps.

<Steps>
  <Step>Go to Meta or any BSPs to create a WhatsApp template.</Step>
  <Step>In the WhatsApp template, add a Type of action 'Visit Website'.</Step>
  <Step>
    You can have 2 types of URL, Static and Dynamic. However if you want to track URL clicks, make sure you select Dynamic URL option.
    <ul>
      <li>
        **Dynamic** - You can use Dynamic URL when you have to send different URLs to different users like Payment links etc. ![](/images/e6fb4d8c118f96b6726b9e4c72c249a5d66eea7753621481a02d4aab9db1f8ed-dynamic_url_meta.png)
        <ol>
          <li>Add a button text which will appear as CTA in your WhatsApp message</li>
          <li>Choose Dynamic as URL Type</li>
          <li>In the website URL, provide this - `https://fy1.in`</li>
          <li>In the Sample URL, provide this - `https://fy1.in`</li>
        </ol>
      </li>
    </ul>
  </Step>
  <Step>Once the template is approved, go to Fyno application , go to _Templates -> External_ and click 'Sync' icon next to WhatsApp. This will sync the template you created in BSPs to Fyno.</Step>
  <Step>Go to _Templates -> Fyno_ and create a Fyno WhatsApp template.</Step>
  <Step>Select 'Synced' and choose the template you got approved in Step 4.</Step>
  <Step>In the buttons section, add the placeholder which you want to track. ![](/images/91a10205f804447f1958b57b2a6969d406123d9b270266ee69146bd63858c757-dynamic_url_fyno.png)</Step>
  <Step>Make sure to add the placeholder in the 'Placeholder' section on the RHS of the template editor.</Step>
  <Step>
    URL Tracking type - There are 2 ways you can track a URL click.
    <ol>
      <li>**General** : Choose this option if you want to track URL clicks only at Notification Event level and not at channel or user level. This is recommended for use cases like creating product URLs for Google/FB Ads and or you want to track only clicks. If you choose this option, you won't see the 'Click' status in the Sent logs or in 'Engagement funnel' chart in Analytics. You will see the cumulative no of clicks under 'URL engagement' chart in analytics.</li>
      <li>**User-Level** : Choose this option, if you want to track URL at user and channel level. This is recommended for use cases like sending unique payment links to users and or you want to track the click event at the message level. If you choose this option, you will see the 'Click' status in the Sent logs and in 'Engagement funnel' chart in Analytics.</li>
    </ol>
  </Step>
</Steps>
