A **Reply: Simple** message is a text or media message that can only be sent as a reply to an existing conversation. No Meta approval is required.

<Note>
This message type can be used only for replies and can't initiate conversations.
</Note>

Set **Message Type** to **Reply: Simple**, then choose a **Content Type**. The fields below the selector change based on the content type.

<Info title="Supported media types">
For a list of supported media types, see [Supported Media Types](https://developers.facebook.com/docs/whatsapp/cloud-api/reference/media/#supported-media-types).
</Info>

<Tabs>
  <Tab title="Text">
    ![](/images/whatsapp_reply_simple_text.png)

    - **Body:** Enter the message text. Use the toolbar above the field for bold, italic, strikethrough and code formatting. Maximum length is 1024 characters.
    - **Show URL preview thumbnail in the message:** Enable this to show a preview thumbnail for any URL in the message.
  </Tab>

  <Tab title="Image">
    ![](/images/whatsapp_reply_simple_image.png)

    - **Caption:** Enter the text to send with the image. The formatting toolbar is available here as well.
    - **Image URL:** Enter the URL of the image, or use the upload icon. The URL must be public. Supported file types are jpeg and png. Images must be 8-bit, RGB or RGBA; images with transparent backgrounds are not supported. The image size should not exceed 5MB.
  </Tab>

  <Tab title="Audio">
    ![](/images/whatsapp_reply_simple_audio.png)

    - **Caption:** Enter the text to send with the audio.
    - **Audio URL:** Enter the URL of the audio file, or use the upload icon. The URL must be public. Supported file types are aac, mp4, amr and mpeg. The audio size should not exceed 16MB.
  </Tab>

  <Tab title="Video">
    ![](/images/whatsapp_reply_simple_video.png)

    - **Caption:** Enter the text to send with the video.
    - **Video URL:** Enter the URL of the video, or use the upload icon. The URL must be public. Supported file types are mp4 and 3gpp. The video size should not exceed 16MB.
  </Tab>

  <Tab title="File">
    ![](/images/whatsapp_reply_simple_file.png)

    - **Caption:** Enter the text to send with the file.
    - **File URL:** Enter the URL of the file, or use the upload icon. The URL must be public, or you can use a PDF component. Any valid MIME type is supported. The file must be under 100MB.
    - **Override Filename:** Enable this to set the filename the recipient sees.
  </Tab>

  <Tab title="Location">
    ![](/images/whatsapp_reply_simple_location.png)

    - **Latitude** and **Longitude:** Enter the coordinates of the location. These are translated into a location on the map. See [how to find coordinates](https://support.google.com/maps/answer/18539?hl=en&co=GENIE.Platform%3DDesktop) in Google Maps.
    - **Location Name:** Enter the name shown with the location.
    - **Address:** Enter the address shown with the location.
  </Tab>

  <Tab title="Sticker">
    ![](/images/whatsapp_reply_simple_sticker.png)

    - **Sticker URL:** Enter the URL of the sticker, or use the upload icon. The URL must be public and the supported file type is webp only. The sticker must be 512x512px, and under 100KB for static or 500KB for animated.
  </Tab>

  <Tab title="Reaction">
    ![](/images/whatsapp_reply_simple_reaction.png)

    - **Reaction:** Enter the emoji to send as a reaction. Maximum 1 emoji allowed.
  </Tab>
</Tabs>

**Reply using WhatsApp Message ID** (optional): To send this message as a reply, provide the WhatsApp message ID of the original message you are responding to. You can select or enter a placeholder for it.

<Warning title="WhatsApp URL redirection will not work">
When providing URLs for files in WhatsApp templates, redirected links (with multiple hops) will not work, as per Facebook policies.
</Warning>
