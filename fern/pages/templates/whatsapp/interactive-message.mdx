A **Reply: Interactive** message is an interactive message with clickable buttons that can only be sent as a reply to an existing conversation. No Meta approval is required.

<Note>
This message type can be used only for replies and can't initiate conversations.
</Note>

## Sub types

Set **Message Type** to **Reply: Interactive**, then choose a **Sub Type**. The available sub types are **Quick replies**, **Menu**, **Request Location**, **Request Address**, **Trigger Meta Flow**, **Order Status**, **Order Details** and **Call to Action**.

### Quick replies

With the **Quick replies** sub type, the message has an optional header, a body, an optional footer, and up to 3 quick reply buttons.

**Header Type:** Choose **None**, **Text**, **Image**, **Video** or **File**. The field below the selector changes based on the header type.

<Tabs>
  <Tab title="None">
    ![](/images/whatsapp_reply_interactive_header_none.png)

    The message is sent without a header.
  </Tab>

  <Tab title="Text">
    ![](/images/whatsapp_reply_interactive_header_text.png)

    - **Title:** Enter the header text.
  </Tab>

  <Tab title="Image">
    ![](/images/whatsapp_reply_interactive_header_image.png)

    - **Image URL:** Enter the URL of the image, or use the upload icon. The image size should not exceed 5MB and should be a valid http image URL.
  </Tab>

  <Tab title="Video">
    ![](/images/whatsapp_reply_interactive_header_video.png)

    - **Video URL:** Enter the URL of the video, or use the upload icon. The video size should not exceed 16MB and should be a valid http video URL.
  </Tab>

  <Tab title="File">
    ![](/images/whatsapp_reply_interactive_header_file.png)

    - **File URL:** Enter the URL of the file, or use the upload icon. The file must be under 100MB and a valid HTTP URL or PDF component.
    - **Override Filename:** Enable this to set the filename the recipient sees.
  </Tab>
</Tabs>

The remaining fields are the same for every header type:

- **Body**: Enter the message text. Use the toolbar above the field for bold, italic, strikethrough and code formatting. Maximum length is 1024 characters.
- **Footer** (optional): Enter the footer text. The formatting toolbar is available here as well.
- **Reply using WhatsApp Message ID** (optional): To send this message as a reply, provide the WhatsApp message ID of the original message you are responding to. You can select or enter a placeholder for it.
- **Buttons**: Click **Add Button** to add up to 3 quick reply buttons. Use the drag handle to reorder them. For each button, enter:
  - **Button Title**: The text shown on the button.
  - **Button Payload** (optional): Data that is captured on an incoming webhook when the button is clicked.

### Other sub types

<AccordionGroup>
  <Accordion title="Menu">
    Provide options from a menu within your WhatsApp message for your customers to choose from.

    - **Message Type:** Text, Image, Video or File.
      - **Image:** The URL must be public. Supported file types are jpeg and png. Images with transparent backgrounds are not supported. You can also upload an image from your device. Maximum size is 5MB.
      - **Video:** The URL must be public. Supported file types are mp4 and 3gpp. Maximum size is 16MB.
      - **File:** The URL must be public. Any valid MIME type is supported. Maximum size is 100MB.
    - **Title:** Mandatory. Give any title to the interactive message. Enable **Preview URL** to show a thumbnail of the URL added.
    - **Body:** Mandatory. Add the body of the message here. You can add any number of placeholders.
    - **Footer:** Optional. You can add placeholders here as well.
    - **Action:** Add interactive buttons.
      - **Button:** The CTA the user sees as part of the interactive message.
      - **Button Id:** Optional. Use a unique ID to identify this button, or to send a payload as part of it.
  </Accordion>

  <Accordion title="Request Location">
    This sub type has a default CTA, **Send Location**.

    - **Body:** Mandatory. Add the body of the message here. You can add any number of placeholders.
  </Accordion>

  <Accordion title="Request Address">
    This sub type has a default CTA, **Provide Address**.

    - **Body:** Mandatory. Add the body of the message here. You can add any number of placeholders.
  </Accordion>

  <Accordion title="Trigger Meta Flow">
    - **Message Type:** Text, Image, Video or File, with the same URL and size rules as the Menu sub type.
    - **Title:** Mandatory. Give any title to the interactive message.
    - **Body:** Mandatory. Add the body of the message here. You can add any number of placeholders.
    - **Footer:** Optional. You can add placeholders here as well.
    - **Flow Settings:**
      - **Type:** Navigate or Data Exchange.
      - **Flow Id:** A unique ID generated by Meta for every flow created.
      - **Flow Token** (optional): Add a unique ID for your flow, or use 'unused'.
      - **Button:** The button title the user sees on the interactive WhatsApp message.
      - **Initial Screen:** The initial screen of the flow.
      - **Additional Data** (optional): If your flow needs a data payload, add it here as a JSON payload.

    ![](/images/b1614f4e0c55064eb4e7d12511428a07989071766297b878dc711ae7fe3f7c21-flow_settings_interactive.png)
  </Accordion>

  <Accordion title="Order Status">
    - **Body:** Mandatory. Add the body of the message here. You can add any number of placeholders.
    - **Footer:** Optional. You can add placeholders here as well.
    - **Order details:**
      - **Order Id:** The order ID for which you are sending this message.
      - **Status:** Processing, Partially Shipped, Shipped, Completed or Cancelled.
  </Accordion>

  <Accordion title="Order Details">
    - **Message Type:** Text or Image. For images, the URL must be public, supported file types are jpeg and png, transparent backgrounds are not supported, and the maximum size is 5MB.
    - **Title:** Mandatory. Give any title to the interactive message.
    - **Body:** Mandatory. Add the body of the message here. You can add any number of placeholders.
    - **Footer:** Optional. You can add placeholders here as well.
    - **List Settings:**
      - **List Type:** **Static** if you know the number of items in the order, **Dynamic** if you don't.
      - **Item Type:** Physical or Digital.
      - **Billing Details** (optional): Name, Address Line 1, Address Line 2, Country, State, City, Postal Code.
      - **Item Details:** Name, Image (optional), Price, Quantity, Sale Price (optional), ID. For a static list, click **+** to add any number of items. For a dynamic list, provide the details of the first item in your array.
      - **Retailer Details**
    - **Payment Settings:**
      - **Gateway:** UPI, Razorpay or PayU.
      - **Configuration Name**
      - **Shipping Cost**
      - **Tax**
      - **Discount**
  </Accordion>

  <Accordion title="Call to Action">
    - **Header Type:** Text.
    - **Title:** Mandatory if you selected Text as the header type. Give any title to the interactive message.
    - **Body:** Mandatory. Add the body of the message here. You can add any number of placeholders.
    - **Footer:** Optional. You can add placeholders here as well.
    - **WhatsApp Message ID:** To send this message as a reply, provide the WhatsApp message ID of the corresponding message. You can provide a static value or enter a placeholder.
    - **Buttons:** Mandatory. Add call to action buttons with:
      - **Button Title:** The CTA users see as part of the interactive message.
      - **URL:** Where users are redirected when they click the button.
  </Accordion>
</AccordionGroup>

<Warning title="WhatsApp URL redirection will not work">
When providing URLs for files in WhatsApp templates, redirected links (with multiple hops) will not work, as per Facebook policies.
</Warning>
