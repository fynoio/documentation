To sync DLT templates: Navigate to → Templates → External → SMS → Sync.

**Sync Option**
The Sync option allows you to:
- Import templates from the DLT platform.
- Refresh approval status.
- Fetch newly approved or rejected templates.

## Steps to Sync
1. Select the DLT provider name from which you want to sync the SMS templates.
2. Upload the CSV file downloaded from the DLT platform. Make sure you upload the file as it is, without making any changes.
3. Click “Sync.”
4. All SMS templates present in the CSV file will now be synced to your Fyno workspace.

This ensures Fyno always reflects the latest provider-side state.
