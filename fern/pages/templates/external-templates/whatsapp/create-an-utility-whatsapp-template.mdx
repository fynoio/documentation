Use a Utility template for transactional messages that follow an action the user already took, such as order confirmations, delivery updates, payment alerts and account notifications. Creating one takes four steps:

1. [Create the template](#step-1-create-the-template)
2. [Build the message](#step-2-build-the-message)
3. [Add more languages](#step-3-add-more-languages-optional) (optional)
4. [Save or send for approval](#step-4-save-or-send-for-approval)

<Note>
Meta may automatically recategorize a Utility template as Marketing based on its template policies. Keep the content strictly about the user's existing activity, such as an order, payment, renewal or alert.
</Note>

## Step 1: Create the template

Navigate to **Templates → External → WhatsApp Templates**, then click **Create**. Fill in the dialog and click **Create Template**.

![](/images/waext-v2-utility-create-dialog.png)

| Field | What to enter |
| --- | --- |
| **Template Name** | A unique name in lowercase, with underscores instead of spaces. For example, `order_shipped_update`. |
| **Integrations** | The WhatsApp Business Account to create the template in. The template can only send messages from this account's phone numbers. |
| **Category** | Select **Utility**. |
| **Language** | One or more languages. You can add or remove languages later. |

## Step 2: Build the message

A Utility message has a header, body, footer and buttons. The Preview on the right shows how it looks.

![](/images/waext-v2-utility-editor.png)

<Steps>
<Step title="Add a header (optional)">

The header appears at the top of the message. For Utility messages, keep it informational. Choose one type.

<AccordionGroup>
<Accordion title="Text">

Enter a short title in **Header Content** (maximum 60 characters), such as _Payment successful_ or _Order update_. You can add one variable, with a sample value.

![](/images/waext-v2-utility-header-text.png)

</Accordion>
<Accordion title="Image">

Click **Choose JPG or PNG file** and upload a sample image (maximum 5 MB).

![](/images/waext-v2-utility-header-image.png)

</Accordion>
<Accordion title="Video">

Click **Choose MP4 file** and upload a sample video (maximum 16 MB).

![](/images/waext-v2-utility-header-video.png)

</Accordion>
<Accordion title="Document">

Click **Choose PDF file** and upload a sample document (maximum 100 MB).

![](/images/waext-v2-utility-header-document.png)

</Accordion>
<Accordion title="Location">

Shows a location, with its name and address, above the message body.

![](/images/waext-v2-utility-header-location.png)

</Accordion>
</AccordionGroup>

<Note>
Media samples are only used by Meta to review your template. Do not include any customer information.
</Note>

</Step>
<Step title="Write the body">

Enter the main message (maximum 1,032 characters). Describe the notification clearly and refer to the user's existing activity. You can format text and add variables. Provide a sample value for every variable so Meta can review the message.

![](/images/waext-v2-utility-body.png)

</Step>
<Step title="Add a footer (optional)">

A short line at the bottom of the message, such as a disclaimer or support info. Maximum 60 characters, with no variables.

![](/images/sample-footer-marketing.png)

</Step>
<Step title="Set the message validity period">

Choose how long Meta tries to deliver the message, for example 30 days. If it isn't delivered in time, you aren't charged and the recipient doesn't see it.

![](/images/message-validity-period-utility.png)

</Step>
<Step title="Add buttons (optional)">

Buttons should help the user complete their existing action. Click **Add Button** and choose a type.

<AccordionGroup>
<Accordion title="Flow (commonly used)">

Opens a WhatsApp Flow.

![](/images/flow-button-utility.png)

| Field | What to enter |
| --- | --- |
| **Button Title** | The button text users see. |
| **Flow ID** | The ID of the flow, generated in Meta. |
| **Flow Action** | **Navigate** opens a specific screen. **Data Exchange** sends or receives data. |
| **Navigate Screen** | The name of the first screen of the flow. |

</Accordion>
<Accordion title="Quick Reply: Custom">

The user sends a predefined reply, such as **Yes** or **No**.

![](/images/quick-reply-button.png)

</Accordion>
<Accordion title="Quick Reply: Marketing Opt-Out">

Lets users opt out of receiving marketing messages.

</Accordion>
<Accordion title="Call to Action: Visit Website">

Opens a website. Use a **static URL** to send the same link to everyone, or select **Dynamic URL** to send a different link to each user, such as a payment link. Select **Track URL** to track clicks with [Fyno Shorty](../../url-shortener).

![](/images/visit-website-curousel.png)

</Accordion>
<Accordion title="Call to Action: Call Phone Number">

![](/images/call-phone-number.png)

</Accordion>
<Accordion title="Call to Action: WhatsApp Voice Call">

![](/images/whatsapp-voice-call.png)

</Accordion>
</AccordionGroup>

</Step>
</Steps>

## Step 3: Add more languages (optional)

To reach users in different regions, click **Add** next to **Languages** and add a version of the template in each language. Translate the message and button text, and keep the same variables in every language.

## Step 4: Save or send for approval

When your template is ready, save it as a draft or send it to Meta for approval. See [Save as Draft vs Send for Approval](./save-or-send-for-approval).
