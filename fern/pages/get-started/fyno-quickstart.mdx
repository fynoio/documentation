Fyno is an all-in-one **Customer Communications Management (CCM)** platform. Connect your providers once, manage every template in one place, and send across SMS, WhatsApp, Email, Push and more through **a single API**, with unified analytics for every channel and provider.

This guide takes you from a fresh account to your first delivered notification in five steps. Each step includes a short video so you can follow along on screen.

<Info>
- **Time needed:** about 15 minutes. &nbsp;
- **You'll need:** a Fyno account and credentials for at least one communication provider (for example, an SMS or email provider).
</Info>

### Configure your integrations

Connect the channels and providers you already use. No custom API integration work is needed on your side.

1. Log in to your existing provider's dashboard and copy its authentication credentials (API keys, tokens, sender IDs and so on).
2. In Fyno, open **Integrations**, select your provider, and paste in the credentials to activate it.

<Tip>
Fyno supports **80+ providers** across SMS, RCS, WhatsApp, Email, Push, Web Push, In-App, Voice, and Chat (Slack, Discord, Teams). Using a provider that isn't listed? Let us know and we'll help you get it added.
</Tip>

→ Learn more in the [Integrations documentation](/docs/integrations-introduction).

### Create your templates

Templates hold all your message content, organised by channel, so your code never has to.

<Frame caption="Video: Creating a template on Fyno">
  <iframe
    width="100%"

    src="https://www.youtube-nocookie.com/embed/QE1CPXjbe54"
    title="Create a template on Fyno"
    allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
    allowFullScreen

</Frame>

- **Edit visually.** Use the WYSIWYG ("What You See Is What You Get") editor to create and edit templates on the fly.
- **Make it dynamic.** Add Handlebars-style `{{ }}` placeholders for values you pass at send time.
- **One template, many channels.** Rich formatting is available on channels like Email and WhatsApp; SMS content is plain text.
- **Test before you ship.** Click **Run Test** to check the template renders as expected.

```handlebars title="Example SMS content with placeholders"
Hi {{name}}, your order {{order_id}} has shipped and will arrive by {{delivery_date}}.
```

<Note>
Already have templates elsewhere? Share them with us and we can pre-load them into your account.
</Note>

→ Learn more in [Templates](/docs/templates-getting-started) and [Handlebars](/docs/templates-handlebars).

### Generate an API key

Every API call to Fyno is authenticated with an API key tied to your workspace.

<Frame caption="Video: Generating an API key on Fyno">
  <iframe
    width="100%"
    style={{ aspectRatio: "16 / 9", borderRadius: "12px", border: 0 }}
    src="https://www.youtube-nocookie.com/embed/sL3yZ14uTS4"
    title="Generate an API key on Fyno"
    allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
    allowFullScreen
  />
</Frame>

1. Click **Workspace Settings** in the bottom-left corner of the navigation menu, then click **API Keys**.
2. Click **Generate +**.
3. Enter a unique name for the key so you can tell your keys apart later.
4. *(Optional)* Enter the IP addresses you want to restrict this key's usage to.
5. Select the environment the key should work in (see the table below).
6. Click the **check mark**, then click **Create**.
7. Before closing the pop-up, copy both your **Workspace ID** and your **API key**.

| Environment | Use it for |
| --- | --- |
| **Both** | A single key that works for Test and Live versions |
| **Test** | Development and testing only |
| **Live** | Production traffic only |

<Warning>
**Save your key right away.** Once the pop-up is closed, the API key can't be retrieved again, and you'll need to generate a new one.
</Warning>

You can create up to **20 API keys** per account. → Learn more in [API Keys](/docs/api-keys).

### Create a notification event

A notification event ties everything together into a single endpoint your application calls to send a message.

<Callout intent="info" icon="fa-solid fa-lightbulb">
**Notification Event** = **Template** + (**Providers** or **Route**)
</Callout>

<Frame caption="Video: Creating and testing a notification event">
  <iframe
    width="100%"
    style={{ aspectRatio: "16 / 9", borderRadius: "12px", border: 0 }}
    src="https://www.youtube-nocookie.com/embed/0c41wXKe83M"
    title="Create and test a notification event on Fyno"
    allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
    allowFullScreen
  />
</Frame>

1. Go to **Notification Events** in the left navigation and click **Create +**.
2. Enter a name, choose the event type (**OTP**, **Transactional**, or **Marketing**), add a description, and select a group. Optionally, choose a subscription topic. Click **Submit**.
3. Under **Template**, select the template you created earlier.
4. Under **Route/Provider**, choose **Single Channel Route or Provider**, then pick a provider or route for each channel in your template.
5. Click **Save** to save a **Test** version, or **Go Live** to publish the **Live** version.
6. Click **Run Test**, enter a destination and placeholder values, and fire a test notification.

Once it works, trigger the event from your application with one API call:

<CodeBlocks>
```bash title="cURL"
curl -X POST 'https://api.fyno.io/v1/<WORKSPACE_ID>/event' \
  -H 'Authorization: Bearer <YOUR_FYNO_API_KEY>' \
  -H 'Content-Type: application/json' \
  -d '{
    "event": "<NOTIFICATION_EVENT_NAME>",
    "to": {
      "sms": "+919876543210",
      "email": "user@example.com"
    },
    "data": {
      "name": "Vivek",
      "order_id": "DEC165432"
    }
  }'
```

```javascript title="Node.js"
const res = await fetch("https://api.fyno.io/v1/<WORKSPACE_ID>/event", {
  method: "POST",
  headers: {
    "Authorization": "Bearer <YOUR_FYNO_API_KEY>",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    event: "<NOTIFICATION_EVENT_NAME>",
    to: { sms: "+919876543210", email: "user@example.com" },
    data: { name: "Vivek", order_id: "DEC165432" },
  }),
});
console.log(await res.json());
```

```python title="Python"
import requests

res = requests.post(
    "https://api.fyno.io/v1/<WORKSPACE_ID>/event",
    headers={"Authorization": "Bearer <YOUR_FYNO_API_KEY>"},
    json={
        "event": "<NOTIFICATION_EVENT_NAME>",
        "to": {"sms": "+919876543210", "email": "user@example.com"},
        "data": {"name": "Vivek", "order_id": "DEC165432"},
    },
)
print(res.json())
```
</CodeBlocks>

<Tip>
**Change without redeploying.** Saving a Test version never affects the Live version in your application. And because your code only references the event name, you can swap templates, channels, or providers on Fyno anytime without touching code.
</Tip>

→ Learn more in [Creating a Notification Event](/docs/notification-event-creation) and [Triggering a Notification Event](/docs/notification-event-triggering).
